## 작업 분담 — A · B · C

기획 확정(2026-08-08) 후 [`treeline.md`](game-design/treeline.md) 의 「만들
시스템」과 「만드는 순서」를 기준으로 나눴다. 각자 **코어 하나 + 장 하나**다.

순서와 근거는 [`tech-design/decisions.md`](tech-design/decisions.md),
구조 규칙은 [`tech-design/architecture.md`](tech-design/architecture.md) 참고.

### 1단계 — 관통

완료 기준은 **처음부터 끝까지 걸어서 엔딩에 도달하고 죽을 수도 있는 것**이다.
회색 박스여도 된다. 여기까지 되면 즉시 빌드해 배포한다.

| | 만드는 것 |
| --- | --- |
| **A** | 1인칭 이동 · 카메라 · 손전등 · 체력 3칸 · 권총 1종 · 탄약 · 피격 판정 |
| **B** | 적 1종(기는 것) 추격 · 공격 · 사망. 그리고 AI 모델 생성 → 리깅 파이프라인 검증 |
| **C** | 1 · 2 · 6 회색 박스, 문 · 레버 최소 상호작용, 씬 전환 · 사망 · 재시작 · 엔딩 |

IMPORTANT: **적 모델이 늦어져도 1단계는 진행되어야 한다.** B 는 캡슐로 추격 ·
공격 · 사망까지 완성하고 모델은 나중에 갈아끼운다. 파이프라인 검증이 1단계를
막으면 안 된다.

### 2단계 — 1 · 2 · 6 에 기믹

장을 한 명씩 인수한다. 회색 박스는 C 가 만들었지만 살을 붙이는 것은 각자다.

| | 담당 장 | 붙이는 것 |
| --- | --- | --- |
| **A** | 6장 승강장 | 삭도 절차, 산탄총, 엔딩 연출 |
| **B** | 2장 숙소동 | 적 2종 추가, 첫 조우 연출 |
| **C** | 1장 관제동 | 장치 3패턴 컴포넌트, 배터리, 양손 운반 |

C 가 장치 3패턴 컴포넌트를 먼저 만들어 공유하면, A 와 B 는 파라미터만 바꿔
자기 장에 쓴다.

### 3단계 — 3 · 4 · 5

여력대로. 5장이 컷라인 1순위라는 기획의 판단을 유지한다.
