# 팀원 롤 기술서

제출물 **"팀원 롤 기술서"** 의 원본이다. 마감 때 이 문서를 PDF 로 변환한다.

과제가 요구하는 세 항목은 쓰는 시점이 다르다.

| 항목 | 언제 |
|---|---|
| 이름 / 담당 역할 | **지금** — 선언하면 된다 |
| 실제로 맡아 구현한 영역 | **마감 때** — 해봐야 아는 것 |
| 협업 · 분업 방식 | **마감 때** — 방식이 굳은 뒤 |

IMPORTANT: 마감 때 기억에 의존해 쓰지 않는다. 아래 세 곳에 근거가 이미 쌓이고
있으므로 그것을 합성한다.

- `git log --author="<이름>"` — 실제로 무엇을 커밋했는지
- `docs/ai/milestones/<이름>.md` — 각자 남긴 작업 메모
- `docs/ai/prompts/<이름>.md` — 어떻게 지시했는지
