# 기획 결정 기록

무엇을 정했는지가 아니라 **왜 그렇게 정했는지**를 남기는 문서다. 기획 문서는
결과만 보여주기 때문에, 이유가 사라지면 나중에 같은 논의를 처음부터 다시 하게
된다.

**게임 기획에 관한 결정만 적는다.** 기술 선택은
[`docs/tech-design/decisions.md`](../tech-design/decisions.md), Claude Code 환경
구성은 [`docs/ai/setup.md`](../ai/setup.md) 로 분리했다. AI 와 논의하다 결론이
바뀐 과정은 `docs/ai/milestones/` 에 남긴다.

## 쓰는 법

새 항목을 **위쪽에** 추가한다. 최근 결정이 먼저 보이는 편이 낫다.

```markdown
## YYYY-MM-DD · <결정을 한 줄로>

<왜 그렇게 정했는지. 무엇을 정했는지보다 판단 근거가 중요하다.>

버린 안: <검토했으나 택하지 않은 것과 그 이유>
```

**"버린 안" 을 생략하지 않는다.** 나중에 "이건 왜 안 했지" 라는 질문을 막아주고,
같은 대안을 다시 검토하는 낭비를 없앤다.
