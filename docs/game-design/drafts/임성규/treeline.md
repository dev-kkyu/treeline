# TREELINE

임성규가 낸 기획안이다. **팀에서 합의된 것이 아니다.** 비교를 위해 올린 것이며,
논의를 거치기 전까지 `docs/game-design/overview.md` 에 반영하지 않는다.

---

## 이게 무슨 게임인가

> 폭설로 길이 끊긴 산꼭대기 통신 중계소.
> 통신이 두절되어 정비공 한 명이 복구하러 올라왔다.
> 사람이 아무도 없다. 그리고 뭔가 있다.
>
> **위에서 아래로 내려가며 산을 빠져나가야 한다.**

이게 전부다. 더 설명할 것이 없다.

- **너는** 정비공이다. 군인도 특수요원도 아니다. 총을 잘 쏘지 못한다
- **여기는** 산꼭대기다. 도움은 오지 않는다. 눈보라로 헬기도 못 뜬다
- **해야 할 일은** 내려가는 것이다. 케이블카 승강장이 산 아래에 있다
- **무서운 이유는** 어둡고, 좁고, 탄약이 부족하고, 혼자이기 때문이다

### 목표는 하나로 이어진다

각 장이 따로 놀지 않게 목적을 사슬로 묶는다.

```
내려가야 한다
   └ 케이블카가 유일한 수단이다              (6장)
        └ 케이블카에는 전력이 필요하다        (4장 발전실)
             └ 승강장까지 가는 길은 밖뿐이다  (5장 외부 철탑)
```

플레이어는 언제나 **"왜 여기 가는지"** 를 안다. 목표를 새로 설명할 필요가
없으므로 컷신이나 지시문이 거의 필요 없다.

## 왜 무서운가

특별한 장치를 두지 않는다. 호러에서 이미 검증된 네 가지만 쓴다.

| | |
| --- | --- |
| **어둡다** | 정전 상태다. 손전등이 비추는 곳만 보인다 |
| **좁다** | 통로와 계단이다. 물러설 곳이 없다 |
| **모자란다** | 탄약이 적다. 쏠지 지나칠지 매번 고민하게 된다 |
| **혼자다** | 무전은 끊겼고 아무도 오지 않는다 |

## 여섯 장소

**6페이즈는 메커니즘 6개가 아니라 거쳐 가는 장소 6곳이다.** 위에서 아래로,
실내에서 실외로 내려간다.

각 장에서 **플레이어가 하는 일**이 하나씩 다르다. 그것이 곧 난이도 곡선이다.

| 장 | 하는 일 | 배우는 것 |
| --- | --- | --- |
| 1 | 둘러본다. 문을 연다 | 조작 |
| 2 | **숨고 도망친다** | 무기가 없을 때는 도망친다 |
| 3 | 조준하고 쏜다 | 탄약을 아낀다 |
| 4 | 다수를 상대한다 | 등 뒤를 본다 |
| 5 | 이동하며 싸운다 | 시야가 나쁠 때 싸운다 |
| 6 | **도망치며 절차를 밟는다** | 못 이기는 상대가 있다 |

2장과 6장이 무력한 구간이다. 처음과 끝에 한 번씩이라 수미상관이 되고, 가운데
넷은 전부 싸운다.

### 1. 관제실 — 아무도 없다

산꼭대기. 도착한다. 계기판이 돌아가고 커피가 아직 따뜻한데 사람이 없다.
의자가 넘어져 있고 바닥에 끌린 자국이 있다.

무기 없음. 손전등을 줍는다. 걷고, 보고, 문을 여는 법을 익힌다.

창밖으로 **거대한 실루엣**이 지나간다. 잘못 본 것 같다.

> 영상 10초 — 평범한 사무 공간, 그리고 창밖의 그림자

### 2. 숙소동 — 처음 만난다

침대와 사물함이 늘어선 좁은 복도. 정전. 손전등만 있다.

**무기가 없다.** 이 장의 교훈은 **"무기가 없을 때는 도망친다"** 이고, 그것을
몸으로 가르치기 위해 여기서만 무기를 주지 않는다.

```
숨죽여 이동한다. 뭔가 지나간다. 사물함 뒤에 붙는다.
복도 끝 문으로 가야 하는데, 손전등을 켜야 문고리가 보인다.
켠다 — 문 앞에 그것이 서 있다.

도망친다. 뒤에서 쫓아온다.
옆방으로 뛰어들어 문을 닫는다. 문이 흔들린다.
```

IMPORTANT: 공정하게 만들려면 두 가지를 지켜야 한다.

- **플레이어가 켜야만 하는 상황을 만든다.** 갑자기 튀어나오는 것이 아니라, 켤
  수밖에 없어서 켰더니 거기 있는 것이다. 내 행동이 부른 결과라야 억울하지 않다
- **도망칠 길이 하나여야 한다.** 2장은 복도다. 미로면 길을 찾다 죽고, 그것은
  무서운 것이 아니라 짜증나는 것이다

3장에서 권총을 쥐었을 때의 안도감이 이 10초에서 나온다.

> 영상 10초 — 어둠, 손전등, 얼굴, 그리고 달린다

### 3. 지하 통로 — 처음 쏜다

배관과 케이블이 지나가는 좁은 통로. 관리실에서 **권총**과 탄약 몇 발을 얻는다.

처음으로 맞선다. 어둠 속에서 쏘면 **총구 섬광이 순간 통로 전체를 비춘다.**
그리고 저 앞에 몇 마리가 더 있는지 보인다.

> 영상 10초 — 어둠 속 섬광, 그 한 프레임에 드러나는 것들

### 4. 발전실 — 둥지

케이블카를 움직이려면 전력이 필요하다. 발전실은 가장 아래층이다.

문을 열면 **벽과 천장이 살과 섬유질로 덮여 있다.** 바닥이 물컹하다. 놈들이
사는 곳이다.

```
차단기 두 개를 찾아 올린다. 흩어져 있어서 돌아다녀야 한다.
이동하는 동안 천장에서 떨어진다. 위를 봐야 한다는 것을 여기서 배운다.

마지막으로 발전기 시동 레버를 당긴다. 시동에 시간이 걸린다.
그동안 사방에서 몰려온다. 버틴다.

전력이 들어온다. 조명이 켜진다.
```

**조명이 켜지는 순간이 이 장의 핵심이다.** 지금까지 손전등이 비추는 곳만 보다가
처음으로 공간 전체가 드러난다. 그리고 내가 무엇 안에서 싸우고 있었는지 보인다.
어둠이 걷히면서 오히려 더 무서워지는 구간이다.

**이 장은 머무는 싸움이다.** 한곳에서 버틴다. 좁고 어둡고 실내다. 다음 장과
정확히 반대로 설계했다.

> 영상 10초 — 유기물로 뒤덮인 공간, 천장에서 떨어지는 것들, 켜지는 조명

### 5. 외부 철탑 — 눈보라

전력은 복구했다. 이제 승강장으로 내려가야 하는데 **실내 통로가 무너져 있다.**
남은 길은 밖뿐이다.

문을 열면 눈보라다. 시야가 몇 미터고 위아래도 잘 구분되지 않는다. 여기서
**산탄총**을 얻는다.

```
철탑마다 유도등이 있다. 하나를 켜면 다음 철탑이 흐릿하게 보인다.
그 불빛만이 방향이다. 놓치면 길을 잃는다.

유도등 세 개를 차례로 켜며 내려간다.
멈추면 몰려온다. 계속 움직이면서 산탄총으로 길을 뚫는다.
```

**이 장은 움직이는 싸움이다.** 멈추면 죽는다. 넓고 하얗고 실외다. 4장이 좁고
어둡고 고정된 싸움이었으므로, 같은 전투인데 정반대의 그림과 정반대의 요령이
된다.

지금까지 어둠이 무서웠는데 여기서는 **하얘서 안 보인다.** 공포의 색이 뒤집힌다.

> 영상 10초 — 하얀 눈보라, 실루엣들, 산탄총 섬광

### 6. 케이블카 승강장 — 큰 것

산 아래. 케이블카를 작동시키면 나갈 수 있다.

**1장에서 창밖으로 본 그것이 온다.** 총이 통하지 않는다. 작동 절차를 밟는
동안 도망치고 숨어야 한다. 처음으로 돌아간 것처럼 다시 무력해진다.

케이블카가 움직인다. 내려가면서 창밖으로 산을 본다.

**화면이 뒤집힌다.** 그것의 시점에서, 케이블카가 멀어지는 것이 보인다.

> 영상 10초 — 거대한 것, 탈출, 그리고 뒤집히는 화면

## 60초 영상

여섯 장소가 각각 10초씩이다. **영상을 위해 따로 만들 것이 없다.**

```
1  아무도 없는 관제실, 창밖의 그림자
2  손전등을 켜니 코앞에 얼굴
3  어둠 속 총구 섬광
4  살로 덮인 공간, 천장에서 떨어지는 것들
5  눈보라 속 실루엣과 산탄총
6  거대한 것, 케이블카, 뒤집히는 화면
```

여섯이 전부 다른 그림이다. 실내 → 복도 → 지하 → 유기물 → 설원 → 탈출.
자막이 없어도 "이 팀이 여섯 개를 만들었다" 가 보인다.

**이 여섯 컷을 먼저 정하고 게임을 역산했다.** 제출물의 핵심이 60초 영상인데,
규칙을 먼저 만들면 영상에 안 보이는 게임이 나온다. 아래 「버린 안」 참고.

## 적 세 종류

**생김새로 구분한다.** 규칙이 아니라 형태다. 어두운 게임이라 대부분 실루엣만
보이므로, 역광에서 검은 그림자만 봐도 구분되어야 한다.

| 적 | 생김새 | 어떻게 상대하나 | 나오는 곳 |
| --- | --- | --- | --- |
| **기는 것** | 네발로 낮게 깔려 빠르다 | 빠르지만 약하다. 권총 한두 발 | 2 · 3 |
| **매달린 것** | 천장에 붙어 있다 떨어진다 | 약하지만 여럿이다. 산탄총 | 4 · 5 |
| **큰 것** | 화면을 채운다. 느리다 | **죽지 않는다. 숨거나 도망친다** | 1 · 6 |

큰 것은 1장에서 창밖으로 실루엣만 보여주고 6장에서 실제로 만난다. 처음과 끝을
잇는다.

## 무기

| | 얻는 곳 | 성격 |
| --- | --- | --- |
| **손전등** | 1장 | 무기가 아니다. 배터리가 닳는다 |
| **권총** | 3장 | 탄약이 적다. 아껴야 한다 |
| **산탄총** | 5장 | 강하지만 느리고 탄이 더 귀하다 |

**탄약이 부족한 것이 이 게임의 긴장이다.** 쏠지 지나칠지 매번 고민하게 만드는
것 하나면 충분하고, 그 이상의 장치는 두지 않는다.

## 규칙

- 어둡다. 손전등을 켜야 보인다. 배터리는 유한하고 곳곳에서 주울 수 있다
- 체력 3칸. 장이 바뀔 때 회복된다. 회복 아이템은 없다
- 붙잡히면 죽는다. 그 장의 시작 지점에서 다시 시작한다
- 지나온 길은 무너진다. 되돌아갈 수 없다

이게 전부다.

## 만드는 순서

```
1(관제실) → 2(숙소동) → 6(승강장)   ← 여기까지가 이미 완결된 게임
                            ↓
              그다음 3 → 4 → 5 를 가운데 끼워 넣는다
```

**끝을 먼저 만든다.** 시간이 모자랄 때 가운데를 잘라내도 게임은 항상 완결
상태다. 1→6 순서로 만들면 마감에 엔딩 없는 게임이 나오고, 그것이 미완성으로
보이는 유일한 경우다.

가운데는 비용이 낮은 순서다. 3장은 권총과 기는 것만 있으면 되고, 4장은 유기물
데코와 매달린 것이 필요하며, 5장은 야외 눈보라 연출이 든다.

적도 같다. **기는 것을 먼저 완성한다.** 셋을 동시에 진행하면 셋 다 미완성이
된다.

## 에셋

| 대상 | 방법 |
| --- | --- |
| 월드 | 에셋스토어 (industrial · bunker · winter) |
| 적 3종 | AI 생성 + 리깅 + 애니메이션 |
| 소품 (손전등, 무기, 계기판) | AI 생성 |
| 사운드 | AI 생성 |

IMPORTANT: **적 3종의 실루엣이 확실히 달라야 한다.** 이 기획에서 적을 구분하는
것은 규칙이 아니라 형태다. 모델링 시트를 만들 때 셋이 **역광에서 검은 실루엣만
보여도 구분되는지**를 기준으로 검수한다. 이것이 안 되면 적 3종을 나눈 의미가
없어진다.

### 검증된 파이프라인

```
ChatGPT      →  모델링 시트 작성
MeshyAI      →  3D 모델 생성
Claude Code  →  Blender 로 리깅 및 애니메이션
```

팀 R&D 로 게임에 넣을 수 있는 품질이 나오는 것을 확인했다. 애니메이션까지
포함해서다. 사운드도 AI 생성으로 조달 가능하다.

IMPORTANT: 이 검증은 저장소 밖에서 이뤄져 자동 로그에 남지 않는다. 담당자가
`docs/ai/milestones/<이름>.md` 에 남겨야 한다. 제출물인 "AI 활용 기술 문서"
에서 가장 값어치 있는 재료인데, 안 적으면 그대로 샌다. 도구 목록은
`docs/assets.md` 에도 기록한다.

### 어두운 게임의 이점

배경이 어두우면 **에셋 품질 요구가 크게 낮아진다.** 텍스처 디테일과 폴리곤이
보이지 않고 조명과 실루엣이 인상을 결정한다. AI 생성 에셋과 에셋스토어 팩을
섞어 쓸 때 이질감이 가장 적게 드러나는 조건이다. 먼 거리를 안 그려도 되므로
WebGL 부담도 준다.

### 시대 · 국적을 특정하지 않는다

현대, 장소 불명으로 둔다. 특정 시대의 소품을 만들기 시작하면 에셋스토어 팩을
쓸 수 없게 되고 비용이 급격히 오른다.

## 제목

`TREELINE` — 수목한계선. 그 위로는 나무가 자라지 못하는 고도.

생명이 끝나는 경계선이라는 뜻이 자연스럽게 붙고, **플레이어의 목표가 정확히 그
선 아래로 내려가는 것**이라 제목이 곧 목표가 된다. 한 단어라 타이틀 카드에서
강하다.

## 저작권

착안 계기는 나홍진 감독의 「호프」(2026) 였으나, 실제로 가져온 것은 **미지의
존재가 위협이 되고 그로부터 탈출한다 / 총기 액션 / 공포 장르** 세 가지뿐이다.
셋 다 `Half-Life`, `Alien: Isolation`, `Metro`, `Resident Evil`,
`S.T.A.L.K.E.R.` 가 공유하는 장르 관습이며 보호받는 표현이 아니다.

그 영화 고유의 설정 — 호포항이라는 지명, 산불→병력차출→통신두절 사슬,
1970년대 한국 어촌, 파출소 소장과 순경이라는 인물 구성 — 은 검토했으나 **전부
버렸다.** 개별 요소는 흔해도 다섯이 한꺼번에 겹치면 실질적 유사성 논란이 되고,
국내 429만 관객에 칸 경쟁부문 초청작이라 심사자가 보았을 확률이 높다. 표절
판단은 법정에 가기 전에 인상으로 온다.

## 버린 안

이 안에 오기까지 네 번 갈아엎었다. 같은 논의를 반복하지 않도록 남긴다.

| 버린 것 | 이유 |
| --- | --- |
| **무전기를 핵심 도구로** | 없어도 게임이 성립했다. 탐지 · 유인 · 이야기 · 퍼즐 네 기능을 얹었는데도 설명할 때마다 이해되지 않았다 |
| **소리를 핵심 규칙으로** | 영상이 무음으로 재생되면 규칙이 아예 존재하지 않는다 |
| **감각으로 구분되는 적** (듣는 것 / 보는 것) | 규칙의 차이라서 화면에 나오지 않는다. 둘 다 "몬스터가 배회한다" 로만 보인다 |
| **전면 잠입** | 10초 클립에 담기는 것이 "웅크리고 걷는 사람" 뿐이다 |
| **빛이 적을 부르는 규칙** | 그림은 좋았으나 또 하나의 설명해야 할 규칙이었다. 어둠과 탄약 부족만으로 긴장은 충분하다 |
| **저절로 변하는 공간** | 이유를 만들지 못했고, 초자연 왜곡은 이 게임의 장르가 아니다. 총이 통하는 세계에 공간 왜곡이 섞이면 플레이어가 세계의 규칙을 믿을 수 없게 된다 |
| **응시 규칙** (보는 것이 상호작용) | 총 · 탈출과 엮이는 방식이 자연스럽지 않았다 |
| **기록 규칙** (카메라로 찍어야 보인다) | 이중 렌더링이 WebGL 에 부담이고, 짧은 기간에 렌더 파이프라인 실험은 도박이다 |
| **즉사** | 액션이 중심이 되면 교전이 성립하지 않는다 |

**공통 원인** — 매번 **영리한 중심 규칙**을 만들려 했다. 그래서 게임을 설명할
때마다 규칙부터 설명해야 했고, 규칙을 이해해야 게임이 그려졌다. 순서가
반대였다. 이 안은 규칙을 최소로 두고 **장소와 사건**으로 대체했다.
