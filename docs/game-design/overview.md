# Treeline

**NHN GAME X AI HACKATHON 사전 과제 · Team SBD (이정범 · 김도한 · 임성규)**

---

## 한 줄 소개

폭설로 고립된 산 위 통신 중계소에서, 정비공 한 명이 시설을 되살려 삭도를
움직이고 산 아래로 내려가는 **1인칭 공포 게임**.

어둡고, 좁고, 총 한 자루로는 부족하고, 혼자다. 총은 한 마리를 죽이고, 시설은 여럿을
죽이고, **죽지 않는 놈도 있다.**

## 게임 방법

### 목표

**산을 내려가는 것.** 유일한 수단은 자재 운반용 삭도이고, 삭도를 움직이려면
시설을 되살려야 한다.

```
내려가야 한다
   └ 삭도가 유일한 수단이다                    (6장 승강장)
        └ 삭도에는 전력이 필요하다             (4장 발전동)
             └ 발전기에는 연료가 필요하다      (3장 연료 갱도)
                  └ 승강장까지 가는 길은 밖뿐이다 (5장 외부 철탑)
```

위에서 아래로, 실내에서 실외로 여섯 장소를 거쳐 내려간다. 목표가 사슬로 이어져
있어 **플레이어는 언제나 왜 여기 가는지를 안다.** 그리고 그 길목마다 **무언가가
돌아다닌다.**

### 조작

| 입력 | 동작 | |

| `W` `A` `S` `D` | 이동 | |
| 마우스 | 시점 | |
| `Shift` | 달리기 | |
| `C` | 웅크리기 — 누르고 있는 동안 | |
| `Space` | 점프 | |
| `F` | 손전등 | |
| `E` | 상호작용 — 문 · 레버 · 밸브 · 차단기, 줍기와 내려놓기 | |
| 마우스 좌클릭 | 사격 | |
| `1` `2` | 무기 전환 — 1 권총, 2 산탄총 | |
| `R` | 재장전 | |
| `Tab` | 일시 정지 — 재개 · 챕터 다시하기 · 환경 설정. 메뉴에서는 뒤로 가기 | |

브라우저가 `ESC` 와 `Ctrl` 을 먼저 가져가므로 (전체 화면 해제 · 페이지 저장) 그
둘은 조작에 쓰지 않는다. 같은 표를 게임 안에서도 볼 수 있다 — 타이틀과 일시 정지
화면의 **「조작키 가이드」**.

달리기에는 **숨**이 있다. 쉬지 않고 5초까지 달릴 수 있고, 멈추면 1.5초 뒤부터
차오른다. 다 쓰면 걷기보다도 느려지므로 도망칠 거리를 남겨두고 써야 한다. 남은 숨은
화면 왼쪽 아래 게이지로 보인다.

총은 **얻어야 쓸 수 있다.** 권총은 3장, 산탄총은 4장에서 얻으므로 그전에는 눌러도
바뀌지 않는다.

**탄약은 무한이다.** 총을 주우면 그때부터 계속 쏠 수 있고 탄약을 찾아다닐 일이
없다. 다만 **탄창이 비면 재장전해야 한다.** 재장전에는 시간이 걸리고 그동안 쏠 수
없다. 정비공이라 손이 빠르지 않다. 화면에는 `▮▮▮▮ x∞` 로 탄창에 남은 발수만 뜬다.

| | 탄창 | 재장전 | 한 발에 | 반동 |
| --- | --- | --- | --- | --- |
| 권총 | 8발 | 1.8초 | 1발 | 가볍다 |
| 산탄총 | 4발 | 2.6초 | **8알이 4.5° 로 퍼진다** | **권총의 세 배** |

**두 총의 무게가 다르다.** 산탄총은 쏠 때마다 총구가 크게 들리고 시야가 벌어지며
화면이 흔들린다. 강한 대신 다음 발까지 조준을 다시 잡아야 한다.

무거운 것(연료통 · 축전지)을 들면 두 손이 차서 **총을 쏠 수 없다.** 내려놓아야
쏜다.

**막히면 「챕터 다시하기」를 고를 수 있다.** 체크포인트가 아니라 그 장의 처음으로
간다 — 막혀서 고른 것인데 체크포인트로 되돌리면 막힌 자리에 다시 데려다 놓기
때문이다. 소지품은 남는다.

**환경 설정**은 타이틀 · 일시 정지 · 엔딩 어디서나 같은 화면으로 뜬다. 음량과
마우스 감도를 조절하고 기본값으로 되돌릴 수 있다.

**게임패드는 지원하지 않는다.** 이동 · 시점 · 사격 · 상호작용까지 바인딩은 되어
있으나 실기로 확인하지 못했고, 손전등과 일시 정지는 키보드 전용이다. **키보드와
마우스로 해주세요.**

### 화면에 뜨는 것

숫자를 쓰지 않는다. **왼쪽 아래에 체력 칸과 숨 게이지, 오른쪽 아래에 탄창**뿐이고,
지금 할 일은 위쪽에 한 줄로 뜬다.

- 맞으면 **화면이 맞은 쪽으로 기운다.** 어디서 맞았는지가 색이 아니라 움직임으로
  온다
- 체력이 **한 칸 남으면 그 칸이 뛴다.** 숫자가 없으므로 「한 대 더 맞으면 죽는다」를
  말할 자리가 여기밖에 없다
- 숨은 **방금 쓴 만큼이 뒤에서 붉게 따라 줄어들고**, 다 차면 푸른빛이 훑는다

### 종료 조건

| | |
| --- | --- |
| **이긴다** | 삭도를 기동해 산을 빠져나간다 |
| **진다** | **놈들에게 붙잡히면** 죽는다. 그 장의 시작 지점에서 다시 시작한다 |

체력은 3칸이고 장이 바뀔 때 회복된다. 회복 아이템은 없다. 세이브 슬롯 없이
장별 체크포인트만 둔다. 죽으면 화면이 닫혔다 다시 열린다.
