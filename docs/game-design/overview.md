## 한 줄 소개

폭설로 고립된 산 위 통신 중계소에서, 정비공 한 명이 시설을 되살려 삭도를
움직이고 산 아래로 내려가는 **1인칭 공포 게임**.

어둡고, 좁고, 탄약이 부족하고, 혼자다. 총은 한 마리를 죽이고, 시설은 여럿을
죽이고, 죽지 않는 것도 있다.

## 게임 방법

### 목표

**산을 내려가는 것.** 유일한 수단은 자재 운반용 삭도이고, 삭도를 움직이려면
시설을 되살려야 한다.

```
내려가야 한다
   └ 삭도가 유일한 수단이다                    (6장 승강장)
        └ 삭도에는 전력이 필요하다             (4장 발전동)
             └ 발전기에는 연료가 필요하다      (3장 연료 갱도)
                  └ 승강장까지 가는 길은 밖뿐이다 (5장 외부 철탑)
```

위에서 아래로, 실내에서 실외로 여섯 장소를 거쳐 내려간다. 목표가 사슬로 이어져
있어 **플레이어는 언제나 왜 여기 가는지를 안다.**

### 조작

<!-- 잠정. 구현하면서 확정하고 여기를 갱신한다. -->

| 입력 | 동작 | |
| --- | --- | --- |
| `W` `A` `S` `D` | 이동 | |
| 마우스 | 시점 | |
| `Shift` | 달리기 | |
| `C` | 웅크리기 — 누르고 있는 동안 (`Ctrl` 도 된다) | |
| `Space` | 점프 | |
| `F` | 손전등 | |
| `E` | 상호작용 — 문 · 레버 · 밸브 · 차단기, 줍기와 내려놓기 | |
| 마우스 좌클릭 | 사격 | |
| `1` `2` | 무기 전환 — 1 권총, 2 산탄총 | |
| `R` | 재장전 | |

총은 **얻어야 쓸 수 있다.** 권총은 3장, 산탄총은 5장에서 얻으므로 그전에는 눌러도
바뀌지 않는다.

탄약은 **탄창과 여분으로 나뉜다.** 화면에 `PISTOL 8 / 24` 로 뜨는 것이 각각
탄창에 든 발수와 남은 여분이다. 재장전에는 시간이 걸리고 그동안 쏠 수 없다 —
권총 1.8초, 산탄총 2.6초다. 정비공이라 손이 빠르지 않다.

| | 탄창 | 여분 최대 | 재장전 |
| --- | --- | --- | --- |
| 권총 | 8발 | 24발 | 1.8초 |
| 산탄총 | 4발 | 12발 | 2.6초 |

무거운 것(연료통 · 축전지)을 들면 두 손이 차서 **총을 쏠 수 없다.** 내려놓아야
쏜다.

게임패드는 이동 · 시점 · 사격 · 상호작용까지 바인딩되어 있으나 검증하지 않았다.
손전등은 키보드 전용이다. 지원 여부는 빌드를 돌려본 뒤에 적는다.

### 종료 조건

| | |
| --- | --- |
| **이긴다** | 삭도를 기동해 산을 빠져나간다 |
| **진다** | 붙잡히면 죽는다. 그 장의 시작 지점에서 다시 시작한다 |

체력은 3칸이고 장이 바뀔 때 회복된다. 회복 아이템은 없다. 세이브 슬롯 없이
장별 체크포인트만 둔다.
