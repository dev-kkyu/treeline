# 제작·Unity QA 체크리스트

## 모델·리그

- [ ] 선택 원본과 같은 얼굴, 짧은 머리, 마른 장신 비례다.
- [ ] 키 1.82m, 눈높이 1.65m, 발바닥 원점이다.
- [ ] 왼쪽 소매의 적갈색 띠·수선 패치가 방향별로 일관된다.
- [ ] 56 export bones: Root 1 non-deform + Humanoid 55 deform다.
- [ ] 전신 20k tris, 1인칭 팔 8k tris 상한을 넘지 않는다.
- [ ] 버텍스당 4 weights 이하, 음수 scale·두 번째 root가 없다.
- [ ] 후드·가슴 스트랩·벨트에 cloth/physics bone이 없다.
- [ ] Humanoid Avatar가 초록색이며 T-pose 경고가 없다.

## 애니메이션

- [ ] 28개 클립 이름·프레임·30fps가 README 표와 같다.
- [ ] 전 클립 Root Motion이 꺼져 있고 Root T/R/Scale에 이동 키가 없다.
- [ ] 모든 루프의 첫/마지막 발·골반 행렬이 동일하다.
- [ ] Walk 2.8, Sprint 4.6, Exhausted 1.8, Crouch 1.4m/s에서 발 미끄럼 5mm 이하다.
- [ ] Crouch 최고점 1.10m, 눈 위치는 코드 0.95m와 ±2cm다.
- [ ] JumpStart→Airborne→Land 전환에서 발이 한 프레임 튀지 않는다.
- [ ] 운반물·레버·밸브·총기 손 IK 오차가 3mm 이하다.
- [ ] 권총 Reload 54f, 산탄총 Reload 78f가 정확하다.
- [ ] 권총 Fire 1f와 산탄총 FirePump 1f가 기존 Fired 시점과 맞는다.
- [ ] Hit보다 Death가 우선하고 Death 마지막 포즈가 반복되지 않는다.

## 1인칭

- [ ] FOV 70/80/90, 16:9와 16:10에서 손·무기가 화면 밖으로 잘리지 않는다.
- [ ] near clip 0.03m에서 장갑 안쪽이나 팔 단면이 보이지 않는다.
- [ ] 권총/산탄총 총구가 중앙 조준점을 가리지 않는다.
- [ ] 카메라 반동과 팔 반동을 함께 켜도 목표 각의 1.5배를 넘지 않는다.
- [ ] Reload 중 무기 전환·운반 시작 시 자세가 기본점으로 복귀한다.
- [ ] 전신 머리 메시가 Main Camera에 렌더되지 않는다.

## 코드·게임플레이

- [ ] CharacterController h1.80/r0.30, 눈높이 1.65/0.95 값이 유지된다.
- [ ] 애니메이션을 제거해도 이동·사격·상호작용·진행이 그대로 동작한다.
- [ ] 운반 중 무기가 보이지 않고 장치 E 상호작용은 계속 가능하다.
- [ ] 권총 8/24/1.8s, 산탄총 4/12/2.6s 탄약 계약이 유지된다.
- [ ] 사망 즉시 입력이 꺼지고 36f 뒤 체크포인트 흐름으로 넘어간다.
- [ ] 발소리는 애니메이션 이벤트가 아니라 PlayerMotor 거리 로직에서 한 번만 난다.

## WebGL

- [ ] 본 수·스키닝 품질을 포함한 Development Build에 오류가 없다.
- [ ] 2048² Body + 1024² Head 텍스처가 메모리 예산을 넘지 않는다.
- [ ] 캐릭터·적·장치가 함께 보이는 장면에서 목표 프레임을 유지한다.
- [ ] Animator parameter 갱신에서 프레임당 GC Alloc 0B다.
- [ ] 전신 그림자와 1인칭 팔이 이중 그림자를 만들지 않는다.
