## 최종 외형 규칙

- 36세 전후, 1.82m의 마른 장신 남성이다. 근육질 군인이 아니라 사다리와 좁은
  통로에 익숙한 현장 기사로 읽혀야 한다.
- 짧게 민 검은 머리, 면도 자국, 피로와 추위가 남은 얼굴을 유지한다.
- 검회색 고칼라 후드 재킷, 가슴 가로 스트랩, 허리 벨트, 탁한 올리브 작업 바지,
  검은 장갑과 안전화를 고정한다.
- **왼쪽 위팔의 적갈색 띠와 수선 패치**가 유일한 방향 판독 표식이다.
- 회사 로고, 국기, 계급장, 방탄복, 탄입대, 홀스터는 추가하지 않는다.
- 후드·스트랩은 몸에 붙어 있으며 천 물리 시뮬레이션을 사용하지 않는다.
