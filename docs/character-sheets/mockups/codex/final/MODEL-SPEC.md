## 1-1. 생성된 모델 실측 (2026-08-09)

Meshy 로 T-pose 를 뽑아 쟀다. 확정값과 맞는 것과 어긋난 것을 같이 적는다.

| 항목 | 실측 | 확정값 | |
| --- | ---: | ---: | --- |
| 신장 | **1.8200 m** | 1.82 | ✓ |
| 양팔 벌린 폭 | 1.832 m | — | 신장과 같다. 해부학적으로 맞다 |
| 어깨 높이 | 1.41 m | — | 어깨 관절 `x ±0.20` |
| 어깨~손목 | **0.52 m** | 0.61 | **9 cm 짧다** |
| 발 길이 | 0.314 m | 0.295 | +2 cm |
| 두 발 간격 | 0.332 m | 골반 0.36 | ✓ |
| 머리 아래끝 | 1.620 m | — | 눈높이 1.65 가 이 안에 든다 |
| 삼각형 | 8,706 | 16,000 목표 | ✓ 여유 |
| 머터리얼 | **1개** | 2개 (Body/Head) | 텍스처가 한 벌이라 나누지 않는다 |

**어깨~손목이 확정값보다 짧다.** 양팔 폭이 신장과 같은 것은 사람의 비례로 맞으므로
모델이 아니라 확정값 쪽이 낙관적이었다고 본다. 1인칭 팔에서는 카메라 기준으로 팔
길이를 다시 잡으므로 문제되지 않고, 전신은 그림자와 엔딩 원경에만 쓰므로 영향이
없다. **모델을 다시 뽑지 않는다.**

머터리얼을 하나로 두는 것도 같은 이유다. 나누려면 UV 를 다시 구워야 하는데,
`M_Protagonist_Head` 로 얻는 것은 얼굴 전용 1024² 하나뿐이고 이 게임에서 주인공
얼굴이 화면에 나오는 장면이 없다.

중립 바운딩박스 용적은 약 **359 L**이며 빈 공간을 포함한다. 76kg 설정의 실제 신체
체적은 약 **74~78 L**로 본다. 두 값은 용도가 다르므로 혼용하지 않는다.

현재 `Player.prefab`의 `CharacterController`는 `h 1.80, r 0.30`, 서 있는 눈높이는
1.65m다. 머리·후드 최고점 2cm는 렌더 메시만 콜라이더 밖에 남기고 플레이 판정을
바꾸지 않는다.

## 2. 메시·LOD 예산

| 대상 | LOD0 목표 / 상한 | LOD1 | LOD2 | 비고 |
| --- | ---: | ---: | ---: | --- |
| 전신 | 16,000 / 20,000 tris | 8,000 | 3,000 | 얼굴·손가락·외곽 우선 |
| 1인칭 팔 | 6,500 / 8,000 tris | — | — | 양팔·장갑·소매, 어깨 일부 |
| 눈·치아 | 전신 예산 포함 | 단순화 | 제거 | 입을 크게 벌리는 대사 없음 |

- 전신은 머리, 몸, 눈을 분리 오브젝트로 둘 수 있으나 export 시 SkinnedMeshRenderer는
  최대 3개다.
- 재킷 지퍼 이, 봉제선, 서리, 작은 긁힘은 Normal/BaseMap으로 처리한다.
- 가슴 스트랩·허리 벨트·큰 버클·후드·포켓 덮개는 외곽 메시로 남긴다.
- 버텍스당 최대 4 weights, 0.01 미만 제거, Normalize All을 적용한다.
- 외투 안 보이는 몸통과 바지 안쪽 다리는 삭제하되 관절 굽힘 여유 2루프는 남긴다.

## 4. 변형·표정

- 얼굴 표정 BlendShape는 `Blink.L`, `Blink.R`, `Pain`, `Dead` 네 개만 만든다.
- 입술 동기화와 대사 표정은 만들지 않는다. 주인공은 설명 대사가 없는 1인칭 캐릭터다.
- 후드, 가슴 스트랩, 허리 벨트, 포켓 덮개는 별도 물리본 없이 몸통·쇄골 본에 스키닝한다.
- 손가락은 장갑 안에서도 권총 탄창과 산탄총 펌프를 잡아야 하므로 5지 구조를 유지한다.

## 5. Unity 프리팹 구성

```text
Player
├─ BodyCollider                  기존 CharacterController
├─ WorldBody                    전신 Humanoid, Main Camera에서 숨김
├─ CameraPivot                  기존 눈높이 1.65 m
│  └─ ViewModelRoot             ViewModel 레이어
│     ├─ ArmsRig                1인칭 팔
│     ├─ PistolSocket
│     ├─ ShotgunSocket
│     └─ CarrySocket
└─ ShadowProxy (선택)           LOD2 전신, 그림자 전용
```

전신과 1인칭 팔은 같은 Humanoid Rest Pose와 손 비례를 쓴다. 카메라에는 전신 메시를
그리지 않고 그림자와 사망 연출 카메라에서만 사용해 머리 안쪽 클리핑을 막는다.
