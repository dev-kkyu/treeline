머티리얼 · 리그와 클립 · 콜라이더와 에이전트.** 위에서 아래로 갈수록 구체적이고,
아래 두 줄은 생성이 끝난 뒤 리깅과 엔진 반영에서 그대로 보고 쓰는 값이다.

## 왜 그림으로 먼저 정하나

기획서가 요구하는 검수 기준이 **형태**다.

> 적 3종의 실루엣이 확실히 달라야 한다. 모델링 시트를 만들 때 셋이 역광에서
> 검은 실루엣만 보여도 구분되는지를 기준으로 검수한다.

글로 「낮고 빠르다 / 천장에 붙는다 / 크다」라고 적어두면 생성 단계에서 셋이 서로
닮아간다. 리깅까지 간 뒤에는 되돌릴 수 없으므로, 되돌릴 수 있는 단계에서
수치로 못 박았다.

셋을 가른 축은 **화면을 채우는 방향** 하나다.

| | 방향 | 비율 | 판별 근거 |
| --- | --- | --- | --- |
| Crawler | 수평 | 2.88 × 0.98m | 낮은 가로 막대 위로 솟은 관절 봉우리 둘 |
| Clinger | 얇은 수직 | 2.51m 늘어짐 | 몸통이 전체 길이의 1/3, 나머지는 얇은 선 |
| Colossus | 두꺼운 수직 | 4.50m | 사람의 2.6배. 최고점이 어깨고 머리가 없다 |

33% 로 줄이고 흐리게 해도 세 방향이 유지되는지까지 `silhouette-check.png` 에서
확인했다.

## MeshyAI 프롬프트

**image-to-3D 로 시트를 참조로 넣는 쪽이 우선이다.** 아래 text-to-3D 프롬프트는
시트가 안 먹을 때의 대안이고, 어느 쪽이든 나온 결과는 시트의 수치로 검수한다.

공통으로 빼는 것 — `no weapons, no armor, no clothing, no eyes, no face,
no fur`. 소품이 붙으면 시대·국적이 특정되고 에셋스토어 팩과 섞을 수 없게 된다.

### Crawler

```
Low quadruped horror creature, extremely horizontal: 2.9m long but only 1m tall.
Emaciated grey-brown flesh. Shoulder and hip joints rise ABOVE the spine line
into two sharp peaks, insect-like crouch. Head thrust forward on no neck, skull
almost touching the ground, split jaw, faceless. Long thin vertebral tail
dragging behind. Neutral standing quadruped pose. Game-ready low-poly, clean
topology, single 1024 texture atlas.
```

### Colossus

```
Massive hunched humanoid horror creature, 4.5m tall. Enormous twin shoulder humps
are the HIGHEST point of the silhouette; the small head is sunken into the valley
between them, below the shoulder line, faceless. Broad slab torso 2.6m wide,
thick arms reaching past the knees down to the ground, short heavy legs, flat
wide feet. Grey fibrous flesh. Slow, immovable, monolithic. Game-ready low-poly.
```

### Clinger

```
Ceiling-dwelling horror creature. Compact teardrop torso only 0.85m long with
four hooked gripping limbs on top for clinging to a ceiling, head hanging below
the torso, and two extremely long thin arms — 1.5x the torso length — dangling
straight down. Total hanging length 2.5m, very narrow vertical silhouette.
Faceless cleft head. Emaciated. Game-ready low-poly.
```

## 머티리얼

전부 [`material-guide.png`](material-guide.png) 에 그림으로 있다. 요지만 옮긴다.

**세 적이 같은 팔레트를 쓴다.** 7색이고 적 모델은 그중 6색만 쓴다(유기물 데코는
4장 벽·천장용이다). 색으로 적을 구분하지 않는다 — 어두운 게임이라 색으로 준
차이는 전달되지 않고, 구분은 형태가 한다.

| 이름 | hex | 명도 | 쓰는 곳 |
| --- | --- | --- | --- |
| 살 · 밝은 | `#8C8279` | 0.52 | 등 · 어깨 · 관절 융기. 손전등이 먼저 닿는 면 |
| 살 · 기본 | `#6E645C` | 0.40 | 몸통 대부분 |
| 살 · 음영 | `#4E463F` | 0.28 | 틈새 · 배 · 겨드랑 · 관절 안쪽 |
| 각질 · 팁 | `#B9AFA2` | 0.69 | 발톱 · 이빨 · 갈고리 끝. 어둠에서 유일하게 밝다 |
| 각질 · 뿌리 | `#2E2A27` | 0.17 | 발톱 · 이빨 뿌리 · 발바닥 |
| 점막 | `#7A3F3C` | 0.30 | 구강 · 갈라진 머리 안쪽. 붉은색은 여기만 |
| 유기물 데코 | `#3A4A46` | 0.28 | 4장 발전동 벽 · 천장 |

IMPORTANT: **살 3단의 명도 차를 0.10 이상 벌린다.** 위 팔레트는 0.52 → 0.40 →
0.28 로 단 차가 0.12 라 규칙을 만족한다. 좁히면 손전등이 닿는 동안에도 형태가
뭉개져 실루엣만 남고, 그러면 적 3종을 나눈 것 말고는 아무 정보도 전달되지 않는다.
`material-guide.png` 아래쪽 「어두운 씬 검수」가 손전등 감쇠를 씌워 이 3단이 어디까지
갈리는지 보여주는 판이다.

점막과 유기물 데코는 살 음영과 명도가 거의 같다. 가까이서 채도로만 갈리는 색이라
형태 판별에는 쓰지 않는다.

### 셰이더와 맵

- **URP Lit · Metallic Workflow · Opaque.** Alpha Clipping 끔
- **맵은 Albedo + Normal 두 장뿐이다.** Metallic·Smoothness 맵을 쓰지 않고
  슬라이더 상수로 둔다 — 살 0.30 / 각질 0.45 / 점막 0.65, Metallic 은 전부 0.0
- **Environment Reflections 끈다.** 어두운 실내에서 큐브맵 반사가 유기물에 얹히면
  플라스틱처럼 보이고, WebGL 에서 공짜가 아니다. Specular Highlights 만 켠다
- 1024² 아틀라스 한 장(텍셀 밀도 약 250 px/m). **Colossus 만 2048²** — 화면을
  채우는 적이라 예외다
- 아틀라스는 몸통·머리 / 팔·다리·척추 / 각질 / 점막 네 구역으로 나누고, **각질
  타일은 셋이 공유한다.** 발톱·이빨·갈고리 끝이 전부 같은 재질이라 세 번 그릴
  이유가 없다
- 임포트에서 **Crunch Compression 을 켠다.** 다운로드 용량이 줄고 런타임 메모리는
  그대로다. 빌드 용량이 곧 심사자가 링크를 누르고 기다리는 시간이다
- Normal 맵은 `Texture Type = Normal map` 이고 sRGB 를 해제한다. 매번 확인한다

머티리얼 슬롯은 적당 1개다. **`Colossus` 만 2개**(`_Body` · `_Wet`)로, 근접
노출이라 구강·가슴 틈새를 Smoothness 0.65 로 뺀다. 나머지 둘은 Smoothness 를
0.30 → 0.35 로 올리는 것으로 젖은 느낌을 대신하고 슬롯을 늘리지 않는다.

젖음 · 피 · 눈은 **머티리얼에 넣지 않는다.** 데칼과 파티클로 얹는다 — 기획의
「불·눈·연기는 시뮬레이션하지 않는다」와 같은 이유다.

## 리그 · 클립 · 콜라이더

각 시트 4행에 표로 있다. 본 이름, 클립 길이(30fps 기준 프레임과 초), 루프 여부,
공격 히트 프레임, 콜라이더와 `NavMeshAgent` 값이 전부 적혀 있다.

| | 본 | 클립 | 특이사항 |
| --- | --- | --- | --- |
| `Crawler` | 24 | 6종 | 손가락 본 없음 |
| `Colossus` | 26 | 6종 | `ShoulderHump` 2본이 실루엣 쌍봉 전용. **Death 없음** |
| `Clinger` | 20 | 8종 | `Grip01~04` 각 2본. `Cling`·`Drop`·`Land` 가 정체성 |

IMPORTANT: `Crawler` 의 콜라이더·에이전트·체력·시야·공격 수치는 **커밋된
`Crawler.cs` · `CrawlerSetup.cs` 의 실측값**이다. 셋 중 코드가 있는 것은 이 하나뿐이므로
**모델을 코드에 맞춘다.** 나머지 둘은 Crawler 를 기준으로 비례해 잡은 제안값이고,
구현할 때 다시 본다.

- `Crawler` — Capsule h 0.9 · r 0.4 · center (0, 0.45, 0) / Agent r 0.4 · h 0.9 ·
  speed 5.5 · 가속 20 · 정지 1.2 / 체력 2 · 시야 18m 120° · 공격 1.6m 1.2s
- 다리는 콜라이더에 넣지 않는다. 보폭 1.52m 는 렌더만이다
- 눈높이 0.5m 는 모델 머리(0.3m)보다 높다. 문턱에 시야 레이가 걸리지 않게 한
  값이므로 **모델을 여기에 맞추지 않는다**
- `Clinger` 는 콜라이더가 두 개다. 매달림은 Sphere r 0.32, 착지는 Capsule h 1.3 ·
  r 0.35 이고 `Land` 마지막 프레임에서 교체하며 그때 Agent 를 켠다. 그 전에 켜면
  공중에서 경로를 잡는다

## 축 규약

세 시트에 같은 내용이 들어 있다. **파이프라인 맨 앞에서 못 박고 그 뒤로는
손대지 않는다.**

- 업 축 — Blender Z-up → Unity Y-up 변환은 FBX 내보내기에서 **한 번만**
- 전방 축 — 모델 로컬 **+Z** 가 전방. 평면도에서 머리가 +Z 를 본다
- 금지 — 리그 −90° / Root 본 +90° 처럼 서로 상쇄되는 보정
- Avatar — 임포터 `avatarSetup = CreateFromThisModel` (Generic)
- 원점 — 발밑 바닥 · 좌우 중앙. 스케일 1.0, 미터 단위

IMPORTANT: 상쇄 구조는 **정지 화면에서 정상으로 보이고 애니메이션이 돌면 눕는다.**
R&D 에서 실제로 이 함정을 밟아 끝내 못 고쳤다
([`../ai/milestones/김도한.md`](../ai/milestones/김도한.md)). 늦게 발견되는
종류의 사고라 규약을 앞에 둔다.

## 그리면서 정해진 것

시트를 그리는 동안 글로는 안 보이던 문제가 두 개 나왔다.

**Clinger 는 자세가 두 개여야 한다.** 늘어진 길이 2.51m 를 천장 2.6m 복도에
그대로 매달면 몸통이 지면 1.6m 까지 내려와 **플레이어가 정면으로 박는다.**
낙하 연출이 성립하지 않는다. 그래서 늘어진 자세는 천장이 높은 4장 발전동
(3.4m 이상) 전용으로 두고, 좁은 곳에서는 **접은 대기 자세**로 천장 아래 0.7m
안에 들어가게 한다. 리그가 접히는 범위를 이 두 자세가 정한다.

**Colossus 총폭 3.44m 는 레벨 제약이다.** 이 적이 지나갈 공간은 4m 이상이어야
한다. 6장 승강장을 만드는 A 이정범에게 모델보다 먼저 넘겨야 하는 수치다.

## 시트를 다시 뽑기

수치를 고치면 그림도 같이 고쳐야 한다. 손으로 그린 것이 아니라
[`sheets.py`](sheets.py) 가 SVG 를 만들고 헤드리스 Chrome 이 PNG 로 굽는다.
수치는 스크립트 상단의 좌표 목록(미터 단위)에 있다.

```bash
python sheets.py <출력폴더>
# 각 .html 을 PNG 로
chrome --headless=new --disable-gpu --no-sandbox --hide-scrollbars \
       --force-device-scale-factor=1.6 --window-size=1800,1346 \
       --screenshot=crawler-sheet.png crawler-sheet.html
```

`silhouette-check` 만 높이가 1200 이다. 외부 의존이 없어서 파이썬과 Chrome
만으로 돈다.

## 아직 안 정한 것

아래는 내가 시트에 적어둔 **제안값**이다. 실제로 생성해 보고 WebGL 빌드에
올려본 뒤 확정한다.

- **트라이앵글 예산** — Crawler 4,000 / Clinger 3,500 / Colossus 9,000. 셋이
  동시에 몇 마리까지 나오는지 정해지면 다시 잡는다. LOD 전환은 12m / 28m
- **본 개수** — 24 / 20 / 26. 리깅해 보고 조인다
- **클립 길이** — 30fps 기준으로 잡았다. 움직이는 것을 보고 조정한다
- **팔레트 hex** — 명도 관계(단 차 0.12)는 지키고 색조는 조정해도 된다
- **Colossus · Clinger 의 콜라이더와 에이전트** — 코드가 없어 Crawler 실측을
  기준으로 비례해 잡았다

IMPORTANT: Colossus 에는 **Death 클립을 만들지 않는다.** 「죽지 않는 것이 있다」가
1장부터 6장까지 안 깨져야 하므로 Stagger 와 Buried 로 끝낸다. 손상 모델도 없다.
