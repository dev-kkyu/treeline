# Colossus 대형 골렘 · 선택 시안 5종

확정 전 탐색안이다. 공통 기준은 Crawler의 쐐기 머리·관절 봉우리·바닥 공격구와
최초 Colossus의 검은 회청색 균열 피부다. 모두 최종 제작 시 높이 4.50m, 총폭
3.44m 이내, 팔 2개·다리 2개, 비발광 눈, 체력 사망 없음으로 맞춘다.

| 안 | 이미지 | 핵심 형태 | 장점 | 제작 리스크 |
| --- | --- | --- | --- | --- |
| A | [Wedge-crown Titan](A-wedge-crown-titan.png) | 삽날 왕관 머리 + 육중한 사지 | Crawler 계보와 보스 체급이 가장 균형적 | 머리와 흉곽 경계 리깅 필요 |
| B | [Knuckle-crawler](B-knuckle-crawler.png) | 초대형 너클 보행 + 작은 후각 | 추격 실루엣이 가장 공격적 | 팔이 화면을 많이 가림 |
| C | [Siege-ram Golem](C-siege-ram-golem.png) | 좌우로 긴 공성추 머리 + 집게손 | 복도 봉쇄와 케이블 잡기가 가장 명확 | 3.44m 폭 관리가 까다로움 |
| D | [Twin-ridge Juggernaut](D-twin-ridge-juggernaut.png) | 이중 등각 + 활처럼 휜 팔 | 가장 짐승 같고 Crawler 확대 진화로 읽힘 | 다른 안보다 눈 판독성이 약함 |
| E | [Fissure Idol](E-fissure-idol.png) | 수직 다안 균열 + 기둥형 하체 | 가장 기괴하고 눈/집게 기능이 명확 | 정지 시 조형물처럼 보일 수 있음 |

Codex 추천 순서는 **A → C → E → B → D**다. A가 원본 Crawler와 Colossus의
중간점을 가장 잘 잡고, C는 6장 승강장의 복도 봉쇄와 케이블 상호작용이 가장 잘
보인다. 선택 후 해당 안만 전·후·좌·우 사방도와 모델링/머터리얼 문서로 확정한다.

생성 방식: Codex 기본 내장 이미지 생성. 각 안은 동일한 두 로컬 참조 이미지를
입력하고 별도 프롬프트로 한 번씩 생성했다.
