# 08 · `Colossus_Threat`

## 역할

- 45f, 30 fps, 1.50초, One-shot, **상체 전용 Additive**.
- 추격 중 주기적으로 나가는 위협이다. 발견 포효(`Roar`)와 달리 **걸음을 멈추지
  않는다.**
- 목적은 하나 — 플레이어가 뒤를 돌아보게 만드는 것이다. 6장은 도망치며 절차를
  밟는 장이고, 뒤가 얼마나 가까운지 계속 알려줘야 압박이 생긴다.

## 왜 Additive 인가

IMPORTANT: 이 클립은 **`Walk_Knuckle` · `Run` 위에 덧씌워진다.** 별도 상태로
만들어 로코모션을 끊으면 추격 중 1.5초마다 멈추게 되어 도망이 너무 쉬워진다.

- Animator 에 **`Upper` 레이어**를 하나 추가하고 Blending 을 Additive 로 둔다.
- 아바타 마스크는 `DEF_Spine01` 이하 전부와 `DEF_Pelvis` · 사지 8본을 **제외**한다.
  즉 `Spine01~03` · `Chest` · `Hump*` · `Head*` · `Jaw` 만 남긴다.
- 첫 프레임이 **기준 포즈**가 된다. Additive 는 첫 프레임과의 차이만 더하므로
  1f 는 반드시 Rest 와 같아야 한다. 어긋나면 걸을 때 상체가 계속 비뚤어진다.

## 키포즈

| 프레임 | 포즈 |
| ---: | --- |
| 1 | Rest 와 **정확히 같다**. 이 프레임이 기준이다 |
| 10 | 흉곽이 6° 비틀리고 쌍봉이 한쪽으로 쏠린다. `Jaw` 8° |
| 20 | **정점.** `Chest` pitch −5°, 머리가 12 cm 올라온다. `Jaw` 26° |
| 26 | 유지. `AE_ColossusThreat` |
| 34 | `Jaw` 10° 로 닫히며 흉곽이 돌아온다 |
| 45 | Rest 와 정확히 같다. **1f 와 값이 같아야 한다** |

## 제작값

- 다리와 골반은 **건드리지 않는다.** 마스크에서 제외했지만 액션에도 키를 넣지
  않는다. 실수로 들어가면 접지가 깨진다.
- 머리 높이 변화는 12 cm 까지. `Roar` 의 1.10 m 와 확실히 구분되어야 한다.
  **위협은 포효의 축소판이 아니라 다른 동작이다.**
- `Jaw` 최대 26°. 포효 45° 와 겹치지 않는다.
- 흉곽 비틀림은 좌우 번갈아 쓸 수 있게 **한 방향으로만** 만든다. Unity 에서
  미러링하거나 `Chest` yaw 부호를 뒤집어 두 번째 변형을 만든다.
- 1f 와 45f 가 Rest 와 정확히 같아야 한다. Additive 의 기준선이 어긋나면 걸을
  때마다 상체가 누적되어 비뚤어진다.

## 언제 나가나

- `IsChasing` 이 참이고 플레이어와의 거리가 **공격 사거리(3.2 m) 밖**일 때.
- 최소 간격 6초. 너무 잦으면 위협이 배경음이 된다.
- `Grab_Miss` · `Stagger` · `Grab_Execute` 중에는 나가지 않는다.

## 「위협 애니메이션들」에 대해

지시는 복수였지만 **한 종류만 만든다.** 변형은 플레이테스트에서 반복이 실제로
눈에 띌 때 추가한다. 지금 두세 개를 만들면 6장에서 각각 몇 번 나오는지 알기
전에 만드는 것이 되고, Crawler 에서 방향별 피격 변형을 미룬 것과 같은 판단이다.

## 검수

- 1f · 45f 포즈가 Rest 와 **정확히** 같다. 재서 확인한다
- 걸으면서 재생했을 때 접지가 깨지지 않는다
- 로코모션 위에 덧씌운 상태로 10주기를 돌려도 상체가 누적되어 기울지 않는다
- 64px 실루엣에서 `Roar` 와 구분된다
