# 00 · 리깅 · 스키닝 명세

## 좌표와 중립 자세

- Blender 는 Z-up, 1 unit = 1 m, 모델 전방은 **-Y** 로 통일한다. FBX 변환 뒤
  Unity 모델 로컬 **+Z** 가 머리 방향이어야 한다.
- 최종 FBX: `-Z Forward / Y Up`, `Bake Space Transform` **끔**, scale 1.0.
  Blender 문서가 이 옵션을 아마추어와 애니메이션에서 신뢰할 수 없다고 명시하며,
  Crawler 에서도 껐다. 축 변환은 Unity 임포터가 한다.
- Rest Pose 는 `Idle_Weight` 1f 와 같다. **생성된 메시의 자세를 그대로 쓴다** —
  네 지점이 모두 바닥에 닿아 있는 너클보행 중립이다.
- `Colossus_Root` 원점은 **네 접지점의 좌우 중앙, 앞뒤 중앙, 바닥 높이**다.
  실측 접지 중심은 손 y −1.40 · 발 y +1.10 이므로 원점은 y −0.15 로 옮긴다.
  좌우는 이미 대칭이라 x 는 그대로 0 이다.
- Armature 와 Mesh 오브젝트의 transform 은 위치 0 · 회전 0 · 스케일 1 을
  적용한다. IMPORTANT: **크기를 Transform 스케일로 만들지 않는다.** `Colossus.cs`
  가 스케일 1 이 아니면 경고를 낸다. 에이전트 반경과 물리가 어긋나기 때문이다.

## Export deform bone · 28개

## 본 롤과 회전 제한

- **모든 deform bone 의 로컬 X 를 월드 +X 로 맞춘다.** `align_roll(X × 본방향)`
  으로 잡으면 된다. 좌우를 미러링하지 않고 같은 축을 쓰는 이유는, 그래야 같은
  부호의 회전이 좌우에서 같은 방향으로 보이기 때문이다. 네발 보행에서는 이쪽이
  스크립트로 다루기 쉽다. Crawler 와 같은 방식이다.
- 굽힘은 로컬 X 하나로만 일어나야 한다. IK 체인에는 Y · Z 를 잠근다.

| 관절 | 굽힘 범위 | 비고 |
| --- | --- | --- |
| `UpperArm` | −45 ~ 50° | 어깨. 팔이 몸 앞뒤로 스윙 |
| `ForeArm` | 0 ~ 95° | 팔꿈치. **바깥으로 활처럼 휜 채 유지** |
| `Wrist` | −40 ~ 35° | 손등 접지에서 각도가 유지되어야 한다 |
| `Digits` | −10 ~ 70° | 평소 0. `Grip_Cable` 에서만 크게 쓴다 |
| `Thigh` | −40 ~ 45° | 고관절 |
| `Shin` | −110 ~ 5° | 역관절. 반대로 꺾이지 않게 제한 |
| `Foot` | −35 ~ 55° | 발목 |
| `Toes` | −15 ~ 30° | **발끝 들림 금지**(시트 §2) |
| `Spine01~03` | pitch ±6° · yaw ±5° · roll ±4° | 세 마디 합이 이 값을 넘지 않는다 |
| `Chest` | pitch ±5° · yaw ±6° · roll ±5° | |
| `Hump` · `HumpTip` | ±4° | 쌍봉은 흉곽과 거의 함께 움직인다 |
| `HeadBase` | pitch ±10° · yaw ±12° · roll ±5° | 목이 없다. 이 이상이면 흉곽이 찢어진다 |
| `HeadTip` | pitch ±5° | 쐐기는 단단하다. 휘게 만들지 않는다 |
| `Jaw` | 0 ~ 55° | 평상시 2°, 포효 45°, 물어뜯기 55° |

IMPORTANT: **`Jaw` 상한을 30° 에서 55° 로 올렸다.** 포효와 처형 클립이 그 이상을
요구한다. 45° 를 넘는 각도에서 입 안쪽이 뒤집히거나 아래턱이 흉곽을 파고들지
`RIG_TEST` 3번에서 반드시 확인한다. 관통하면 각도를 줄이지 말고 **스키닝을
고친다** — 입이 크게 벌어지는 것이 이 적의 유일한 얼굴 표현이다.

IMPORTANT: **`HeadBase` pitch 한계는 올리지 않는다.** 목이 없어서 10° 를 넘기면
흉곽 경계가 찢어진다. 포효할 때 머리를 젖히고 싶으면 **머리가 아니라 몸 앞쪽
전체를 세운다** — `Pelvis` 를 뒤로 앉히고 `Spine01~03` 과 `Chest` 를 함께
일으켜 머리를 들어 올린다. 목이 없는 생물이 포효하는 방법이고, 머리만 젖히는
것보다 훨씬 크게 보인다.

축 부호는 실제 bone roll 에 따라 달라질 수 있으므로 숫자의 +/− 를 억지로 맞추지
말고 **해부학적 굽힘 방향과 최대 각도**를 맞춘다.

## 컨트롤 리그

Crawler 에서 확인한 대로, **컨트롤 리그는 사람이 뷰포트에서 집어 옮기기 위한
것이고 내보내는 본에는 포함되지 않는다.** 스크립트로 만드는 이 파이프라인에서는
최소한만 둔다.

- 네 접지점에 `CTRL_LimbIK.FL` · `.FR` · `.HL` · `.HR` 을 둔다. 앞은 손(Wrist
  tail), 뒤는 발(Foot tail)이 목표다.
- 앞다리 IK chain 2(`ForeArm` + `UpperArm`), 뒷다리 IK chain 2(`Shin` + `Thigh`).
  `Wrist` 와 `Foot` 은 IK 타깃의 회전을 Copy Rotation 한다.
- pole target 을 만들지 않는다. 대신 무릎 · 팔꿈치에 **IK 축 잠금(Y · Z)과
  위 표의 회전 제한**을 걸어 뒤집힘을 막는다. 팔꿈치는 Rest 에서 이미 바깥으로
  휘어 있어 방향이 확정된다.
- `Colossus_Motion` 은 연출용이다. `Grip_Cable` 처럼 Root 를 쓸 수 없는 클립에서
  전체를 통째로 옮길 때만 쓴다. 나머지 클립에서는 0 을 유지한다.

IMPORTANT: **`Colossus_Root` 는 모든 클립에서 위치 · 회전 0 이다.** 이동과 회전은
`NavMeshAgent` 가 한다. Root Motion 은 쓰지 않는다.

## 스키닝

- 한 vertex 최대 4 weights, 0.01 미만 제거, Normalize All. Unity Import 의
  Skin Weights 는 4 Bones.
- **쌍봉은 흉곽과 거의 강체로 붙인다.** `Hump` 계열 가중치를 0.85 이상으로 주고
  변형은 흉곽과의 경계 2~3 루프에만 분산한다. 쌍봉이 출렁이면 이 적의 「눌린
  압력 덩어리」라는 인상이 사라진다.
- **목이 없다는 것이 이 모델의 스키닝에서 가장 까다로운 곳이다.** 머리는 흉곽
  아래에 파묻혀 있어 경계가 짧다. `HeadBase` 와 `Chest` 를 경계 3 루프에서
  30/70 → 55/45 → 80/20 으로 넘긴다. 머리가 12° 이상 돌아가면 이 구간이
  찢어지므로 위 표의 제한을 반드시 지킨다.
- `HeadTip` 은 쐐기 전체를 0.9 이상으로 잡아 거의 강체로 만든다.
- `Jaw` 는 입 틈 아래쪽만 가져간다. 입술 가장자리 → 안쪽 순으로
  `HeadTip`/`Jaw` 를 80/20, 45/55, 10/90 으로 넘긴다. **닫힘에서 관통하지 않는
  것이 우선**이다.
- **손등 접지 부위**(`Digits` 와 `Wrist` 경계)는 체중이 실리는 곳이다. 관절
  중심 루프를 50/50, 앞뒤 한 루프를 75/25 로 시작하고, `Wrist` 를 35° 꺾었을 때
  손등이 접히지 않고 눌리는지 확인한다.
- 3지는 각각 `Digits` · `Toes` 한 본에 100% 가까이 묶는다. 손가락이 개별로
  휘면 안 된다.
- 어깨 · 고관절의 관절 봉우리는 해당 `UpperArm`/`Thigh` 와 `Chest`/`Pelvis`
  사이에만 섞는다. **반대편 사지의 weight 가 넘어오면 안 된다.** 팔이 몸통
  가까이 지나가는 구조라 자동 가중치가 이 실수를 하기 쉽다.
- 필요하면 corrective shape key 를 써도 되지만 FBX 에는 최종 bake 한다.
  시트 §3 이 블렌드셰이프를 요구하지 않으므로 임포트에서는 끈다.

## Rig 검수 포즈

애니메이션 전에 한 액션 `RIG_TEST` 에서 확인하고 이 액션은 export 하지 않는다.

1. 네 접지점을 각각 0.40 m 들어 IK/무릎 뒤집힘이 없는지 확인.
2. 몸통을 0.25 m 내려 네 다리가 모두 압축될 때 팔꿈치가 흉곽을 관통하지 않는지
   확인. **팔이 몸 옆을 스치는 구조라 여기가 가장 위험하다.**
3. `Jaw` **55°** 개방에서 입 안쪽 면이 뒤집히거나 사라지지 않고, 아래턱이
   흉곽을 파고들지 않는지 확인. 포효 45° · 물어뜯기 55° 가 이 각도를 쓴다.
4. `HeadBase` 를 yaw 12° 로 돌렸을 때 흉곽과의 경계만 변형되고 쐐기가 휘지
   않는지 확인.
5. `Digits` 를 70° 로 감았을 때 손가락이 손바닥을 관통하지 않는지 확인
   (`Grip_Cable` 과 `Grab_Execute` 가 이 각도를 쓴다).
6. 모든 컨트롤을 Rest 로 되돌렸을 때 네 접지점의 높이 차가 3 mm 이하인지 확인.
