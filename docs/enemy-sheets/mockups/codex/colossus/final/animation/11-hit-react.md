# 11 · `Colossus_Hit_React`

## 역할

- 18f, 30 fps, 0.60초, One-shot, **상체 전용 Additive**.
- 밀림 임계(누적 4)에 **닿지 않은** 피격에 나간다. 임계에 닿으면
  [`Stagger`](04-stagger.md) 가 대신 나간다.
- 걸음을 끊지 않는다. 맞으면서 계속 온다.

## 앞 문서에서 「만들지 않는다」고 한 것을 뒤집었다

[`README.md`](README.md) 초판은 이 클립을 만들지 않기로 했다. 근거는 「맞아도 아무
반응이 없는 것이 총이 통하지 않는다를 가장 강하게 전달한다」였다.

**반응이 없으면 맞았는지도 모른다는 것이 더 큰 문제다.** 플레이어는 자기 총알이
적중했는지를 알아야 한다. 명중 피드백이 없으면 「통하지 않는다」가 아니라
「버그인가?」가 된다.

**해결은 반응의 종류를 바꾸는 것이다.** 몸을 밀지 않고 **살갗만 움찔하게** 한다.
맞은 것은 보이되 걸음도 자세도 흔들리지 않는다 — 그게 「통하지 않는다」다.

## 왜 Additive 인가

[`Threat`](08-threat.md) 와 같은 `Upper` 레이어에 얹는다. 별도 상태로 만들면
피격마다 로코모션이 끊겨 오히려 총이 잘 듣는 것처럼 보인다.

- 마스크는 `Threat` 와 동일 — `Spine01~03` · `Chest` · `Hump*` · `Head*` · `Jaw`.
- 1f 가 Rest 와 정확히 같아야 한다.
- `Threat` 와 같은 레이어이므로 **동시에 나가지 않는다.** 피격이 우선이다.

## 키포즈

| 프레임 | 포즈 |
| ---: | --- |
| 1 | Rest 와 정확히 같다 |
| 3 | **충격.** `Chest` 가 피격 방향으로 2.5° 눌린다. `Jaw` 6° |
| 6 | 쌍봉이 12 mm 흔들린다. 흉곽이 되돌아오기 시작 |
| 11 | 70% 복귀. `Jaw` 3° |
| 18 | Rest 와 정확히 같다 |

## 제작값

- **전체 진폭이 `Stagger` 의 1/3 이하다.** `Chest` 2.5° 대 7°, 쌍봉 12 mm 대
  20 mm. 두 클립이 헷갈리면 밀림의 의미가 사라진다.
- `Pelvis` · 사지는 건드리지 않는다. 마스크에서 빠지지만 액션에도 키를 넣지 않는다.
- 머리는 **움직이지 않는다.** 계속 플레이어를 겨눈 채다. 이게 가장 무섭다.
- 0.6초는 `attackCooldown` 2.4초보다 짧고 연사 간격보다 길다. 연사로 쏘면 반응이
  겹쳐 끊기는데, Additive 레이어에서 같은 상태로 재진입하면 자연스럽게 덮인다.
- 좌우 방향은 만들지 않는다. `Chest` roll 부호를 코드에서 뒤집어 쓴다.

## 코드 계약

`TakeDamage()` 에서 임계 미만일 때 `HitReact` 트리거를 보낸다. 현재는 아무것도
보내지 않는다.

```text
damageSinceStagger += amount
if (damageSinceStagger >= staggerThreshold)  -> Stagger 트리거
else                                          -> HitReact 트리거
```

`Buried` 중에는 보내지 않는다.

## 검수

- 1f · 18f 포즈가 Rest 와 정확히 같다
- 걸으면서 · 달리면서 재생해도 접지가 깨지지 않는다
- `Stagger` 와 한눈에 구분된다. 나란히 재생해 확인한다
- 연사로 5발을 쏴도 상체가 누적되어 기울지 않는다
- **맞았다는 것은 알겠는데 아파 보이지는 않는다.** 이 클립의 합격 기준이다
