# 검수 체크리스트

순서대로 본다. **앞 항목이 통과하지 않으면 뒤를 보지 않는다** — 리그가 틀린 채로
만든 클립은 전부 다시 만들어야 하기 때문이다.

## A. 리그 (`00-rigging.md`)

- [ ] deform bone 이 정확히 28개, non-deform 이 `Root` · `Motion` 둘이다
- [ ] Armature · Mesh 의 위치 0 · 회전 0 · **스케일 1**. `Colossus.cs` 가 스케일
      1 이 아니면 경고를 낸다
- [ ] 원점이 네 접지점의 중앙, 바닥 높이다
- [ ] Rest Pose 에서 네 접지점의 높이 차가 3 mm 이하다
- [ ] `RIG_TEST` 6개 항목이 모두 통과한다
- [ ] 정점당 가중치가 4 이하이고 0.01 미만이 없다
- [ ] `HeadBase` 를 yaw 12° 로 돌려도 쐐기가 휘지 않고 경계만 변형된다
- [ ] `Digits` 70° 에서 손가락이 손바닥을 관통하지 않는다

## B. 클립 공통

- [ ] 여섯 클립의 이름이 `README.md` 표와 정확히 같다
- [ ] `Colossus_Root` 의 위치 · 회전이 **모든 클립에서 0** 이다
- [ ] `Grip_Cable` · `Buried` 외의 클립에서 `Colossus_Motion` 이 0 이다
- [ ] 30 fps 다. Blender 씬 기본값은 24 이므로 **반드시 확인한다**
      (Crawler 에서 모든 클립이 1.25배로 늘어난 적이 있다)
- [ ] 바닥 관통이 5 mm 이하다 (`Buried` 제외)
- [ ] `Death` 라는 이름의 클립 · 상태 · 파라미터가 없다

## C. 루프 클립 (`Idle_Weight` · `Walk_Knuckle`)

- [ ] 첫 프레임과 마지막 프레임의 **모든 본 포즈가 정확히 같다**. 눈으로 보지
      말고 잰다
- [ ] 경계에서의 속도 변화가 클립 내부의 최대 접지 순간보다 작다
- [ ] 모든 주기 항이 정수 배음이다. **1.5 같은 값이 하나라도 있으면 실패다**
- [ ] 복제 끝 프레임을 포함해 내보냈다

## D. `Walk_Knuckle`

- [ ] **모든 프레임에서 접지가 3점 이상**이다. 프레임마다 센다
- [ ] 접지 중인 손 · 발이 미끄러지지 않는다 (한 접지 구간당 4 cm 이하)
- [ ] 손등이 먼저 닿고 손가락이 뒤따른다
- [ ] 발끝이 −10° 이상 들리지 않는다
- [ ] 1.15 m/s 에서 재생 배속이 1.0 ± 0.1 안이다
- [ ] 64px 실루엣에서 **팔로 걷는 것**이 읽힌다 (1장 창밖 연출)

## E. `Attack_Push`

- [ ] 14f 실루엣만으로 예고가 보인다
- [ ] 20f 에 가장 큰 형태 변화가 온다
- [ ] 뒤 두 발이 전 구간 접지를 유지한다
- [ ] 팔이 흉곽을 관통하지 않는다
- [ ] **이 클립에서는 체력이 한 칸도 깎이지 않는다**
- [ ] 20f 에서 손이 빈 것이 보인다. 잡은 것처럼 보이면 안 된다
- [ ] 1~8f 가 `Grab_Execute` 와 구분되지 않는다

## F. `Stagger`

- [ ] 48f(1.60초)이며 코드의 `staggerSeconds` 와 같다
- [ ] 네 점 중 최소 두 점이 항상 접지한다
- [ ] 고통 표현이 없다. 밀린 질량으로만 보인다
- [ ] 48f 뒤 `Walk_Knuckle` 과 섞어도 pop 이 5° / 3 cm 이하다

## F2. `Roar` · `Turn` · `Run`

- [ ] `Roar` 가 36f(1.20초)다. 기획서의 「1.2 초」와 같아야 한다
- [ ] `Roar` 4f 정지 구간이 실제로 완전히 멈춰 있다
- [ ] `Roar` 에서 머리가 몸통보다 먼저 돌아본다
- [ ] `Roar` 22f 를 1인칭 눈높이(1.65 m)에서 보면 화면이 가려진다
- [ ] `Roar` 에서 **머리를 젖히지 않고 몸 앞쪽을 세운다**. `HeadBase` pitch ±10° 안
- [ ] `Jaw` 45° · 55° 에서 아래턱이 흉곽을 파고들지 않는다
- [ ] `Turn` 모든 프레임에서 접지 3점 이상. 접지 중인 사지는 제자리 회전이 아니라
      뗐다 놓는다
- [ ] `Turn` 을 에이전트 55°/s 와 함께 재생했을 때 발이 미끄러지지 않는다
- [ ] `Turn_L` 이 `Turn_R` 의 정확한 거울이다
- [ ] `Run` 비접지 구간이 한 번에 2프레임을 넘지 않는다
- [ ] `Run` 1f 와 37f 의 모든 본 포즈가 정확히 같다 (C 절과 같은 기준)
- [ ] **플레이어가 전력질주로 `Run` 을 벗어날 수 있다.** 실제로 달려서 확인한다

## F3. Additive 두 개 (`Threat` · `Hit_React`)

- [ ] 두 클립 모두 **1프레임과 마지막 프레임이 Rest 와 정확히 같다.** 재서 확인
- [ ] 액션에 `Pelvis` · 사지 키가 하나도 없다
- [ ] 걸으면서 · 달리면서 재생해도 접지가 깨지지 않는다
- [ ] 10주기를 돌려도 상체가 누적되어 기울지 않는다
- [ ] `Hit_React` 진폭이 `Stagger` 의 1/3 이하다. 나란히 재생해 확인
- [ ] `Hit_React` 중 머리가 움직이지 않는다
- [ ] 연사 5발에도 상체가 누적되지 않는다
- [ ] `Threat` 가 64px 실루엣에서 `Roar` 와 구분된다

## F4. `Grab_Execute`

- [ ] 1~8f 가 `Attack_Push` 와 구분되지 않는다
- [ ] **40~64f 에 입이 화면 중앙에 있다.** 실제로 카메라를 붙여 본다
- [ ] 카메라 각속도가 84f 이전 구간에서 90°/s 를 넘지 않는다
- [ ] 뒤 두 발이 전 구간 접지
- [ ] 왼손이 `GrabAnchor` 에 정확히 맞춰 잠겨 있다
- [ ] `AE_GrabLock` 이 8f, `AE_GrabKill` 이 90f 에 각각 한 번씩
- [ ] **체력이 몇 칸이든 잡히면 죽는다.** 3칸에서 시험한다
- [ ] `Attack_Push` 로 갈렸을 때 체력이 한 칸도 깎이지 않는다
- [ ] **90f 이전에는 플레이어가 죽지 않는다**
- [ ] 클립이 중간에 끊겨도 플레이어가 손에 붙은 채 남지 않는다
- [ ] 체력이 3칸일 때는 `Attack_Push`, 2칸 이하일 때만 `Grab_Execute` 가 나간다
- [ ] **네 번 연속으로 죽어봐도 짜증나지 않는다**

## G. `Grip_Cable` · `Buried`

- [ ] `Grip_Cable` 34f 이후 뒤 두 발이 지면 아래로 내려가지 않는다
- [ ] `Grip_Cable` 42f → `Buried` 1f 의 pop 이 8° 이하다
- [ ] `Buried` 의 `Colossus_Motion` 하강이 1.9 m 를 넘지 않는다
- [ ] `Buried` 60f 에서 머리가 위를 향한다
- [ ] **`EyeAnchor` 에 카메라를 붙여 52~60f 를 재생했을 때 멀미가 나지 않는다.**
      실제로 붙여서 본다. 각속도 10°/s 이하
- [ ] `Buried` 가 죽음이 아니라 갇힘으로 보인다

## H. Unity 연결 (`unity-integration.md`)

- [ ] 열세 클립이 이름 그대로 임포트되고 길이가 표와 같다
      (`Turn_L` · `Turn_R` 을 따로 세어 13개)
- [ ] Loop Time 이 `Idle_Weight` · `Walk_Knuckle` · `Run` 셋에만 켜져 있다
- [ ] Blend Tree 가 `Speed` 0 / 1.15 / 2.60 로 되어 있다
- [ ] **`Upper` 레이어가 Additive 이고 마스크가 상체만 남긴다**
- [ ] `Turn` Blend Tree 가 `TurnDir` −1 / +1 로 되어 있다
- [ ] `Buried` 전이가 최우선이고 되돌아오지 않는다
- [ ] 밀림 임계 미만의 피격에 `Hit_React` 가 나가고 로코모션이 끊기지 않는다
- [ ] `Roar` 가 재발견마다 나가지 않는다 (`loseInterest` 12초 초과 시에만)

- [ ] `stopping distance` 가 2.60 이다
- [ ] `angularSpeed` 가 55 그대로다 (`Turn` 클립이 그 값에 맞춰져 있다)
- [ ] `agent.speed` 가 배회 1.15 · 추격 2.60 으로 바뀐다
- [ ] 6장의 이동 경로 폭이 5.30 m 이상이다
- [ ] 본체 Collider 가 팔을 통과시키지 않는다
- [ ] `OnDrawGizmosSelected` 의 통로 상자가 실측값으로 고쳐졌다
- [ ] `attackDamage` 로 체력이 깎이는 경로가 코드에 남아 있지 않다
- [ ] (나중에) 포효 소리를 생성해 `AE_ColossusRoar` 에 연결한다
