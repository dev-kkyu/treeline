# COLOSSUS-FINAL-1.0 · 모델 스펙

선택 원본은 `D-twin-ridge-juggernaut.png`다. 아래 수치는 이미지 픽셀 추정값이
아니라 Blender 블록아웃과 Unity 프리팹에서 맞출 **제작 기준값**이다. 축은 Unity
기준 `X=폭`, `Y=높이`, `Z=깊이`, 전방은 로컬 `+Z`다.

밀폐된 최종 메시에서 Blender `3D Print Toolbox > Volume`으로 다시 기록한다.

## 3. 메시·LOD

| 구분 | 목표 | 상한 | 보존 대상 |
| --- | ---: | ---: | --- |
| LOD0 | 9,000 tris | 11,000 tris | 쌍봉, 팔 활, 머리 쐐기, 손·발 3지 |
| LOD1 | 4,500 tris | 5,200 tris | 외곽선과 관절 위치 |
| LOD2 | 1,500 tris | 1,800 tris | 검은 실루엣과 입 틈 |

- 한 버텍스 최대 4 weights, 0.01 미만 weight 제거.
- 압력 균열은 Normal/BaseMap으로 처리하고 지오메트리로 파지 않는다.
- 손가락·발가락은 실루엣 메시로 분리하지만 개별 물리 콜라이더는 만들지 않는다.

## 4. 리그

| 구분 | 수량 | 구성 |
| --- | ---: | --- |
| 전체 본 | 30 | non-deform 2 + deform 28 |
| non-deform | 2 | `Root`, `Motion` |
| 몸통 | 5 | Pelvis 1, Spine 3, Chest 1 |
| 쌍봉 | 4 | 좌·우 각 2 |
| 머리·턱 | 3 | HeadBase, HeadTip, Jaw |
| 팔 | 8 | 좌·우 각 UpperArm, ForeArm, Wrist, DigitsGroup |
| 다리 | 8 | 좌·우 각 Thigh, Shin, Foot, ToesGroup |

손·발 3지는 각각 `DigitsGroup`/`ToesGroup` 한 본으로 묶는다. 개별 손가락 본은
추가하지 않는다. Death 클립과 절단용 본은 만들지 않는다.
