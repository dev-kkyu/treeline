# 모델링 설계

## 1. 공통 형태 언어

세 적은 같은 종처럼 보이되, 같은 골격을 확대·축소한 것처럼 보여서는 안 된다.
공통점은 해부학이 아니라 표면에서 만든다.

- 큰 면 70%, 관절과 접힘 25%, 균열 디테일 5%로 배분한다.
- 모든 주름은 몸의 압력을 받는 방향으로 흐른다. 무작위 피부 노이즈는 넣지 않는다.
- 흰 서리 흉터는 가장 돌출된 큰 면과 관절 가장자리에만 둔다.
- 인간 얼굴과 노출 안구는 만들지 않는다. 현재 Final 세 종은 모두 무안이다.
- 팔다리는 최소 1개 축에서 비대칭을 허용하되, 이동 판정에 영향을 주는 길이는 맞춘다.
- 역광 축소 이미지에서 종을 맞히지 못하면 디테일을 추가하지 말고 큰 덩어리를 고친다.

## 2. Crawler · 바닥 쐐기

빠르고 약한 첫 적이다. 플레이어의 손전등 아래쪽을 갑자기 채우는 형태로 만든다.

| 항목 | 확정값 |
| --- | --- |
| 전체 길이 | 2.88 m (몸통+머리 1.90m, 꼬리 약 0.98m) |
| 몸통 높이 | 0.67 m |
| 최고 높이 | 0.98 m |
| 최대 폭 | 1.52 m (보폭 포함) |
| 기본 자세 | 앞이 넓고 뒤가 가는 낮은 쐐기, 머리는 바닥 0.12 m 위 |
| LOD0 / 1 / 2 | 4,000 / 2,000 / 700 tris, LOD0 상한 5,200 |
| 본 상한 | 24 deform bones |

### 조형

- 머리와 가슴을 하나의 삽날 같은 덩어리로 묶는다. 위에서는 둔한 삼각형이다.
- 공격구는 머리 아래에 가로 틈으로 숨긴다. 평상시에는 검은 선 하나만 보인다.
- 앞다리는 짧고 벌어져 제동과 방향 전환을 담당한다.
- 뒷다리는 길고 Z자로 접혀 추진을 담당한다. 네 다리의 관절 실루엣을 같게 만들지 않는다.
- 꼬리는 몸통보다 가늘고 평소 바닥을 스친다. 공격 무기로 쓰지 않는다.

### 토폴로지

- 머리 아래 공격구에 3개 루프, 어깨/고관절에 각 3개, 무릎/발목에 각 2개를 둔다.
- 등과 옆구리는 큰 사각 면을 유지한다. 균열은 지오메트리로 파지 않고 Normal로 표현한다.
- 발가락은 앞발 3갈래 실루엣만 모델링하고 개별 본을 두지 않는다.

### 리그와 클립 · 30 fps

| 클립 | 길이 | 루프 | 핵심 포즈 |
| --- | ---: | :---: | --- |
| `Idle_Low` | 45f | O | 호흡보다 등판의 미세한 압력 이동 |
| `Skitter` | 24f | O | 좌우 다리가 어긋나는 빠른 보행 |
| `Sprint` | 18f | O | 꼬리를 들어 실루엣을 더 길게 만듦 |
| `Attack_Underbite` | 22f | X | 8f 예고, 13f 공격구 최대 개방/히트 |
| `Hit` | 12f | X | 낮은 중심을 유지한 옆 밀림 |
| `Death` | 30f | X | 다리가 접히며 쐐기 덩어리가 바닥에 붙음 |

Root motion은 끈다. 이동 거리는 `NavMeshAgent`가 담당하고 발 미끄러짐은 속도
파라미터로 보정한다.

## 3. Clinger · Ceiling Crawler Husk Final

천장에서는 심장형 압착 덩어리로 웅크리고, 낙하하면서 굵은 수직 위협으로 변한다.
세부 제작값은 [`clinger/final/MODEL-SPEC.md`](clinger/final/MODEL-SPEC.md)가 우선한다.

| 항목 | 확정값 |
| --- | --- |
| 접힌 크기 | 0.88 × 0.72 × 0.62 m (X×Y×Z) |
| 펼친 길이 | 2.51 m |
| 착지 높이 | 1.42 m |
| 최대 폭 | 갈고리 포함 1.10 m |
| LOD0 / 1 / 2 | 4,200 / 2,100 / 700 tris, LOD0 상한 5,200 |
| 본 상한 | 24 deform bones |

### 조형

- 몸통은 전체 길이의 41%를 차지하는 굵은 심장형 압착 덩어리다.
- 천장 사지는 정확히 4개이며 사지마다 각질 갈고리 2개로 부착한다.
- 공격 팔은 정확히 2개이며 굵은 역관절과 손 3지로 아래쪽 외곽을 만든다.
- 머리는 몸통 아래에 매몰된 Crawler형 쐐기이고 공격구는 아래 가로 입이다.
- 노출 눈, 리본, 마름모 외피, 곤충 갑각, 다리, 꼬리는 금지한다.

### 리그와 클립 · 30 fps

| 클립 | 길이 | 루프 | 핵심 포즈 |
| --- | ---: | :---: | --- |
| `Cling_Folded` | 60f | O | 천장 아래 0.72m 유지, 몸통 3~5mm 호흡 |
| `Cling_Tremor` | 36f | O | 관절 봉우리 네 개가 다른 위상으로 떨림 |
| `Unfold_Drop` | 24f | X | 10f에 하단 해제, 18f에 완전 수직 |
| `Land` | 18f | X | 15f부터 지상 콜라이더/Agent 활성 |
| `Scuttle` | 24f | O | 착지 자세에서 비대칭 4점 보행 |
| `Attack_Underjaw` | 22f | X | 9f 예고, 13f 아래턱/양손 히트 |
| `Hit` | 10f | X | 굵은 팔 하나가 과회전 후 복원 |
| `Death` | 28f | X | 갈고리가 풀리고 몸통이 옆으로 낙하 |

천장 상태는 Root를 천장 접점에 둔다. `Unfold_Drop`은 포즈만 만들고 실제 낙하는
코드/중력으로 처리해 천장 높이 변화에 대응한다.

## 4. Colossus · Twin-ridge Juggernaut Final

죽지 않는 마지막 적이다. Crawler의 쐐기 머리와 솟은 관절 봉우리를 4.5m급
너클 보행 골격으로 확장한다. 세부 제작값은
[`colossus/final/MODEL-SPEC.md`](colossus/final/MODEL-SPEC.md)가 우선한다.

| 항목 | 확정값 |
| --- | --- |
| 전체 높이 | 4.50 m |
| 최대 폭 | 3.44 m (몸통 폭 2.64m) |
| 깊이 | 2.10 m |
| 하부 통과 폭 | 없음. 플레이어가 다리 사이로 통과하지 못함 |
| LOD0 / 1 / 2 | 9,000 / 4,500 / 1,500 tris, LOD0 상한 11,000 |
| 본 상한 | 28 deform bones |

### 조형

- 앞뒤로 긴 쌍봉 등각 둘이 4.50m 최고점이고 중앙에 0.32m 골짜기를 만든다.
- 머리는 목 없이 흉곽 아래에 묻힌 낮은 쐐기다. 노출 안구는 0개이며 아래 가로 입만 둔다.
- 팔은 정확히 2개로 바깥쪽 활을 만들고 손은 지면에 닿는다. 다리는 정확히 2개로
  팔 안쪽에서 하중을 지지한다.
- 손·발은 각 3지다. 손은 케이블 파지, 발은 넓은 접지만 수행한다.
- 꼬리, 뿔, 갑옷판, 바위 덩어리, 추가 사지는 금지한다.

### 리그와 클립 · 30 fps

| 클립 | 길이 | 루프 | 핵심 포즈 |
| --- | ---: | :---: | --- |
| `Idle_Weight` | 72f | O | 쌍봉과 흉곽이 10~15 mm만 비틀림 |
| `Walk_Knuckle` | 54f | O | 팔 접지 후 반대 다리 이동, 항상 3점 이상 지지 |
| `Push` | 34f | X | 20f에 양팔과 머리 쐐기로 밀기 |
| `Grip_Cable` | 42f | X | 손 3지가 케이블을 감쌈 |
| `Stagger` | 30f | X | 임계 피격 시 코드가 2.50m 후퇴 |
| `Buried` | 60f | X | 죽지 않고 눈/잔해 아래 움직임 유지 |

`Death` 클립과 절단/손상 모델은 만들지 않는다. 피격은 체력 감소가 아니라 누적
밀림과 짧은 `Stagger`만 발생한다.

## 5. 축 · 원점 · 스키닝

- Blender: Z-up, -Y forward로 작업하고 FBX export에서 `-Z Forward / Y Up`,
  Apply Transform을 사용한다. Unity 임포트 후 모델 로컬 +Z가 실제 진행 방향인지
  프리팹에서 확인한다.
- 단위: 1 Blender unit = 1 m, export scale 1.0.
- 원점: 지상 적은 바닥 접점의 바운드 중앙. Clinger는 천장 접점 Root와 지상용
  `GroundPivot` 보조 본을 둔다.
- Generic rig. 한 버텍스 최대 4 weights, 0.01 미만 weight 제거.
- Twist가 필요한 긴 사지는 1개 twist bone만 허용한다. 얼굴/손가락 본은 없다.
- Negative scale, Armature 오브젝트 회전 보정, 중복 Root는 금지한다.

## 6. 콜라이더 초안

| 적 | 본체 콜라이더 | 공격 범위 | Agent |
| --- | --- | --- | --- |
| Crawler | Capsule Y, h 0.90, r 0.40, center y 0.45 | 전방 Box 0.85×0.45×0.75 | r 0.40, h 0.90, speed 5.5 |
| Clinger 천장 | Sphere r 0.46 | 낙하 경로 SphereCast | Agent off |
| Clinger 지상 | Capsule Y, h 1.34, r 0.48 | 전방 Capsule r 0.52, h 0.85 | r 0.48, h 1.42, speed 4.2 |
| Colossus | Box 2.90×4.20×1.60 | 전방 Box 3.20×3.20×1.40 | r 1.35, h 4.50, speed 1.15 |

팔다리에는 물리 콜라이더를 달지 않는다. 피격용 Hitbox가 필요하면 머리/몸통/사지
3그룹으로만 나누고, Colossus는 어느 부위를 맞아도 같은 밀림 값만 사용한다.

## 7. 검수 기준

- 64 px 높이의 완전 검정 실루엣만 보고 3종을 1초 안에 구분할 수 있다.
- Crawler는 화면 아래 1/3, Clinger는 화면 위에서 중앙으로, Colossus는 좌우를
  동시에 막는다.
- 손전등 정면 2 m에서 큰 면 3개, 6 m에서 외곽선과 공격구만 읽힌다.
- 애니메이션 중 외곽선이 다른 적의 기본 형태로 바뀌지 않는다.
- LOD1 전환 시 균열은 줄어도 외곽선과 관절 위치는 변하지 않는다.
