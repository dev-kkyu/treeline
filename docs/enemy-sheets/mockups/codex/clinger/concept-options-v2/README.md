# Clinger · 체형 보강 선택 시안 5종

1차 후보의 지나치게 가늘고 우아한 인상을 폐기하고 Crawler·Colossus Final과 같은
압착 생체 계보로 다시 만든 2차 탐색안이다. 세 적의 공통점은 검은 회청색 피부,
큰 압력 균열, 쐐기 머리, 솟은 관절 덩어리, 3지 손이다.

Clinger의 역할은 그대로 유지한다. 전개 길이 2.51m, 최대 폭 1.10m, 접힌 높이
0.72m 이내, 천장 부착 사지 4개, 공격 팔 2개다. 몸통 비율은 전체 길이의
40~45%로 키우고 관절 단면도 1차 후보보다 약 1.7배 굵게 잡는다.

| 안 | 이미지 | 핵심 형태 | 가족 정합 | 역할 판독 | 제작 리스크 |
| --- | --- | --- | ---: | ---: | --- |
| A | [Wedge pod](A-wedge-pod.png) | Crawler 쐐기낭 + 굵은 장완 | 높음 | 매우 높음 | 눈이 작아 근접 보강 필요 |
| B | [Twin-ridge pendant](B-twin-ridge-pendant.png) | Colossus 쌍봉을 뒤집은 육중한 추 | 매우 높음 | 보통 | 폭과 접힌 크기 관리 필요 |
| C | [Ceiling crawler husk](C-ceiling-crawler-husk.png) | Crawler형 심장 몸통 + 아래턱 | 매우 높음 | 높음 | Crawler와 지나치게 닮을 수 있음 |
| D | [Pressure-bell brute](D-pressure-bell-brute.png) | 두 압착 엽 + 중앙 다안 균열 | **최고** | 높음 | 두 엽과 팔의 충돌 스키닝 필요 |
| E | [Inverted knuckle](E-inverted-knuckle.png) | M자 몸통 + 굵은 너클 장완 | 매우 높음 | 높음 | 눈 판독성이 약함 |

Codex 추천은 **D → A → E → C → B**다. D는 Colossus와 같은 압착 쌍봉 구조를
쓰면서 중앙 다안 균열과 천장 부착으로 역할이 분리된다. A는 Crawler 계보를 가장
쉽게 알아보면서도 전개 실루엣이 명확한 안전한 선택이다.

선택 후 해당 안만 `CLINGER-FINAL-1.0`으로 승격하고 정·후·좌·우·상·하 6면도와
별도 모델 스펙을 작성한다. 1차 후보는 비교 기록으로 보존한다.

생성 방식: Codex 기본 내장 이미지 생성. Crawler 정면, Colossus Final 정면,
최초 Clinger 정면을 각각 골격·질감·역할 참조로 입력하고 후보별 프롬프트를 독립
실행했다.
