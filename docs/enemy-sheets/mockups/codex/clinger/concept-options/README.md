# Clinger · 선택 시안 5종

확정 전 탐색안이다. 최초 Clinger의 검은 회청색 균열 피부와 v2의 뒤틀린 관절·
비발광 눈을 표면 기준으로 삼되, 기존 리본·마름모 몸체는 복제하지 않았다.

모든 안의 공통 제작 기준은 펼친 길이 2.51m, 접힌 높이 0.72m 이내, 몸통은 전체의
상단 1/3, 천장 갈고리 사지 4개, 공격 장완 2개다.

| 안 | 이미지 | 핵심 형태 | 장점 | 제작 리스크 |
| --- | --- | --- | --- | --- |
| A | [Needle-spire](A-needle-spire.png) | 바늘 골격 다발 + 7안 씨앗 머리 | 가장 가늘고 원거리 판독성이 좋음 | 몸통 면적이 작아 피격 판정 보강 필요 |
| B | [Organ-chime](B-organ-chime.png) | 갈비 새장 + 장기낭 + 다안 종머리 | 접힘/펼침 구조와 천장 부착이 가장 명확 | 상단 장기낭의 스키닝 비용이 큼 |
| C | [Inverted marionette](C-inverted-marionette.png) | 매듭 몸통 + 노출 척추 + 9안 두부 | 관절 뒤틀림과 낙하 공포가 가장 강함 | 긴 척추가 이동 애니메이션에서 흔들릴 수 있음 |
| D | [Spiral lantern](D-spiral-lantern.png) | 삼중 나선 몸통 + 내부 눈 사슬 | 가장 독창적이고 징그러우며 회전 동작에 강함 | 나선 겹침의 토폴로지·LOD 관리 필요 |
| E | [Split bell](E-split-bell.png) | 갈라진 두 엽 + 내부 16안 | 접으면 숨고 펼치면 눈이 드러나는 연출이 명확 | 눈 개수와 두 엽의 UV 면적이 큼 |

Codex 추천 순서는 **D → B → C → E → A**다. D가 기존 시안과 가장 다르면서도
낙하·회전·공격 애니메이션을 한 형태 언어로 연결한다. B는 실제 리깅과 접힌 대기
자세를 가장 쉽게 설명할 수 있는 안전한 선택이다.

선택 후 해당 안만 `CLINGER-FINAL-1.0`으로 승격하고 정·후·좌·우·상·하 6면도와
별도 모델 스펙을 작성한다.

생성 방식: Codex 기본 내장 이미지 생성. 최초 Clinger와 v2 정면을 질감·관절·눈
참조로만 입력하고, 각 안은 서로 다른 프롬프트로 한 번씩 독립 생성했다.
