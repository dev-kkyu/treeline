# CLINGER-FINAL-1.0 · 모델 스펙

선택 원본은 `concept-options-v2/C-ceiling-crawler-husk.png`다. 아래 값은 이미지
픽셀 추정이 아니라 Blender와 Unity에서 맞출 제작 기준이다. 축은 Unity 기준
`X=폭`, `Y=높이`, `Z=깊이`, 전방은 로컬 `+Z`다.

실제 생물 체적은 밀폐된 최종 메시에서 별도로 측정한다.

## 4. 메시·LOD

| 구분 | 목표 | 상한 | 보존 대상 |
| --- | ---: | ---: | --- |
| LOD0 | 4,200 tris | 5,200 tris | 심장 몸통, 봉우리 4, 쐐기 입, 사지 수량 |
| LOD1 | 2,100 tris | 2,500 tris | 몸통 외곽과 굵은 관절 축 |
| LOD2 | 700 tris | 900 tris | 천장 덩어리/전개 수직 실루엣 |

- 버텍스당 최대 4 weights, 0.01 미만 weight 제거.
- 균열은 BaseMap/Normal로 처리하고 지오메트리로 파지 않는다.
- 갈고리·손가락은 외곽 메시로 남기되 개별 물리 콜라이더는 만들지 않는다.

## 5. 리그

| 구분 | 수량 | 구성 |
| --- | ---: | --- |
| 전체 본 | 26 | non-deform 2 + deform 24 |
| non-deform | 2 | `Root`, `GroundPivot` |
| 몸통 | 3 | TorsoBase, TorsoMid, TorsoTip |
| 머리·턱 | 2 | Head, Jaw |
| 천장 사지 | 8 | 사지당 Upper, Lower |
| 공격 팔 | 8 | 좌·우 각 Upper, Fore, Hand, DigitsGroup |
| 접힘 보조 | 3 | FoldBody, FoldArmL, FoldArmR |

갈고리 두 개와 공격 손가락 세 개는 각각 그룹 본 하나로만 움직인다. 얼굴·눈 본은
없다. 천장 상태 Root는 천장 접점, 착지 후 이동은 `GroundPivot`을 사용한다.
