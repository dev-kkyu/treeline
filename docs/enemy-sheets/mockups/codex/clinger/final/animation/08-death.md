# 08 · `Clinger_Death_Fall` · `Clinger_Death`

상태: 2026-08-09 개정. 한 클립 28f → 두 클립 18f + 36f.

## 왜 둘로 나눴는가

초판은 한 클립이 천장 사망과 지상 사망을 모두 덮게 했다. 리그에서 두 상태는
`GroundPivot`이 만드는 **2 m 짜리 평행이동**으로 갈린다. 한 액션의 커브가 두 위치에
동시에 있을 수 없으므로 나누는 것이 최소 수정이다.

천장에서 죽으면 `Death_Fall` → (코드 낙하) → 바닥 접촉 → `Death`로 이어진다.
지상에서 죽으면 `Death`만 재생한다.

---

# `Clinger_Death_Fall` · 18f / 0.57초 / One-shot

천장 상태에서만 재생한다. 갈고리가 순서대로 풀리고 힘이 빠진 채 떨어진다.

| 프레임 | 단계 | 포즈 / 이벤트 |
| ---: | --- | --- |
| 1 | 치명타 | 현재 천장 자세. 공격/이동 중단, `Dead` 고정 |
| 3 | 경축 | **한 번 굳는다.** 사지 4개가 동시에 3° 조이고 턱이 18° 벌어진 채 멈춤 |
| **5** | 해제 시작 | `AE_DeathRelease` 1회. LF 갈고리 IK 0으로 |
| 7 | | RR 놓음. 몸이 놓인 쪽으로 기울며 roll 14° |
| 9 | | RF 놓음. roll 26°, 남은 LR 하나에 전체가 매달린다 |
| 11 | 완전 해제 | LR 놓음. 네 IK 모두 0. 코드 낙하 시작 |
| 14 | 무력 | 팔·사지가 몸통을 **2f 늦게** 따라오며 위로 흐른다. 턱 24° 열린 채 |
| 18 | 유지 | 시체 자세. 바닥에 닿을 때까지 hold |

- 갈고리는 사라지거나 부러지지 않고 **장력만 순서대로 풀린다.** 순서 LF→RR→RF→LR은
  대각선이 번갈아 풀리는 것이라 몸이 좌우로 두 번 기운다.
- 몸통 roll 최대 **34°**. 180° 뒤집기와 회전 누적은 금지.
- 18f 포즈는 `Death` 1f와 실루엣이 이어져야 한다. 완전히 같을 필요는 없다 —
  사이에 코드 낙하가 들어가므로 자세만 연속이면 된다.

# `Clinger_Death` · 36f / 1.17초 / One-shot

지상 상태에서 재생한다. 천장 사망은 바닥에 닿은 뒤 이어서 재생한다.

| 프레임 | 단계 | 포즈 / 이벤트 |
| ---: | --- | --- |
| 1 | 치명타 | GroundPose 또는 `Death_Fall` 18f에서 진입 |
| 4 | **경축** | 사지 여섯이 **안으로 오그라든다.** 손가락 40°, 척추가 뒤로 30° 젖혀짐. 턱 34° 벌어진 채 굳음. `AE_DeathRelease` |
| 9 | 정점 | 등이 1.18 m까지 솟는다. 죽는 것이 아니라 **버티는 것**으로 보이는 프레임 |
| 14 | 풀림 | 힘이 한꺼번에 빠진다. 척추 −18°, 앞팔이 접히며 등이 0.55 m로 무너짐 |
| 20 | 붕괴 | 몸통 roll **58°**. 사지 굽힘이 좌우 3f 어긋난다 |
| 26 | 옆 자세 | roll **78°**, 한쪽 몸통 면이 바닥을 향한다. 팔이 몸 밑에 깔림 |
| 31 | 마지막 경련 | **한쪽 손가락만** 30° 쥐었다 편다. 다른 곳은 이미 멈췄다 |
| 36 | 시체 | 모든 deform curve 정지. tangent flat |

## 왜 먼저 경축하는가

초판은 4f부터 곧장 힘이 빠지게 했다. 그러면 「스위치가 꺼졌다」로 읽힌다.
4~9f에 **반대 방향으로 한 번 긴장했다가** 14f에 무너지면 죽는 데 시간이 걸린 것으로
보인다. 31f의 마지막 경련도 같은 목적이고, 여기가 클립에서 가장 싸게 얻는 불쾌함이다.

## 제작값

- Root 위치/회전 0. 붕괴의 수직 이동은 `GroundPivot`이 만든다.
- 몸통 roll 최대 **78°**(초판 32°). 옆으로 눕는 데 필요한 값이고, 90°를 넘기면
  등이 바닥을 향해 사지가 하늘로 뻗어 만화가 된다.
- 접지 IK는 14f에 전부 0으로 내린다. 그 뒤로는 사지가 몸통을 **2~3f 늦게** 따라온다.
- 바닥 관통은 20f 이후 **10 mm**까지 허용한다. 시체는 바닥에 눌리는 편이 자연스럽다.
- 마지막 프레임의 tangent를 flat으로 하고 Cycles/Noise를 제거한다.

## 코드 계약

- `AE_DeathRelease`는 천장 Sphere / 지상 Capsule / Agent를 모두 끄고 사망 낙하를
  시작한다. `Death_Fall`은 5f, `Death`는 4f에 있다.
- 천장 높이가 커 `Death_Fall` 18f 뒤에도 공중이면 마지막 포즈로 계속 떨어지며,
  SphereCast가 바닥을 만나면 Transform 이동을 멈추고 `Death`로 넘어간다.
- 시체 유지시간과 제거 시간은 아직 코드가 없으므로 구현 단계에서 확정한다.

## 검수

- 천장·지상 두 시작 상태 모두 첫 9f 안에 사망이 명확하다.
- 여섯 사지가 서로 관통하거나 추가 다리처럼 펼쳐지지 않고 몸통 쪽으로 오그라든다.
- `Death_Fall` 18f와 `Death` 1f 사이에 실루엣 도약이 없다.
- 36f 이후 curve가 완전히 멈추며 collider가 플레이어와 총알을 막지 않는다.
