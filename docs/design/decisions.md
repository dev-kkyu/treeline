# 기획 결정 기록

무엇을 정했는지가 아니라 **왜 그렇게 정했는지**를 남기는 문서다. 기획 문서는
결과만 보여주기 때문에, 이유가 사라지면 몇 주 뒤 같은 논의를 처음부터 다시 하게
된다.

제출물인 "AI 활용 기술 문서" 의 재료이기도 하다. Claude 와 논의하다 결론이 바뀐
과정은 특히 값어치가 있으므로 함께 적는다.

## 쓰는 법

새 항목을 **위쪽에** 추가한다. 최근 결정이 먼저 보이는 편이 낫다.

```markdown
## YYYY-MM-DD · <결정을 한 줄로>

<왜 그렇게 정했는지. 무엇을 정했는지보다 판단 근거가 중요하다.>

버린 안: <검토했으나 택하지 않은 것과 그 이유>
```

**"버린 안" 을 생략하지 않는다.** 나중에 "이건 왜 안 했지" 라는 질문을 막아주고,
같은 대안을 다시 검토하는 낭비를 없앤다.

기획이 아니라 기술 선택에 관한 결정은 나중에 만들 기술 문서 쪽에 적는다.
