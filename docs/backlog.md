진행 중인 작업 관리용이 아니라 **잊으면 곤란한 것** 목록이다. 끝난 항목은

## WebGL → GitHub Pages 배포 경로 검증

**아직 한 번도 성공한 적이 없다.** 이게 안 되면 나머지가 전부 무의미해지는
유일한 항목이다.

빈 씬을 WebGL 로 빌드해 `gh-pages` 브랜치로 배포하고, 브라우저에서 열리는 것까지
확인하면 된다. 압축 설정, MIME 타입, 경로 문제로 처음에 자주 막히는 구간이다.

IMPORTANT: **프로젝트가 비어 있는 지금이 가장 싸다.** 게임이 커지면 빌드만
십수 분이고, 문제가 나도 원인이 게임 쪽인지 배포 쪽인지 가려야 한다. 기획과
무관하므로 언제 해도 된다.

## Unity MCP 구성

Claude 가 씬·GameObject·컴포넌트·프리팹을 직접 조작할 수 있게 하는 연동이다.
스택을 Unity 로 정한 핵심 근거였는데 (`docs/tech-design/decisions.md` 참고)
아직 붙이지 않았다.

구현체를 고르고 `.mcp.json` 에 팀 공용으로 등록한다.

**첫 코드를 쓰기 전에 붙이는 편이 낫다.** 나중에 붙이면 그 전에 만든 것들은
수동 작업으로 남아, 제출물 "AI 활용 기술 문서" 에 쓸 재료가 그만큼 줄어든다.

## 문서 PDF 변환 파이프라인

`docs/` 의 마크다운을 공용 CSS 를 거쳐 PDF 로 만드는 경로다. 변환할 내용이 아직
없어 급하지 않다.

다만 한글 폰트 누락이나 페이지 나눔 문제는 마감 직전에 만나면 뼈아프다. 내용이
비어 있어도 **한 번 돌려서 PDF 가 나오는 것까지는 확인해두는 편이 안전하다.**
