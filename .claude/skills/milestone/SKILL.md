# 마일스톤 메모 남기기

이 프로젝트는 NHN GAME X AI 해커톤 사전 과제이고, **AI를 어떻게 활용했는지가
심사 대상**이다. 프롬프트 원본은 훅이 자동으로 쌓지만, 그것만으로는 마감 때
맥락을 복원하기 어렵다. 이 메모가 그 간극을 메운다.

## 절차

1. 작성자 이름을 확인한다.

   ```bash
   git config user.name
   ```

   비어 있으면 사용자에게 물어본다. 임의로 정하지 않는다.

2. `docs/ai/milestones/<이름>.md` 에 **append** 한다. 기존 내용을 덮어쓰지
   않는다. 파일이 없으면 `# AI 활용 마일스톤 - <이름>` 제목으로 새로 만든다.

3. 아래 형식으로 항목을 추가한다. 날짜는 오늘 날짜를 쓴다.

   ```markdown
   ## YYYY-MM-DD · <한 줄 제목>

   <본문>
   ```

## 무엇을 쓰나

이번 세션에서 **실제로 일어난 일만** 쓴다. 지어내지 않는다. 다음을 담는다.

- **무엇을 AI로 했는가** — 만든 것, 고친 것
- **어떻게 지시했는가** — 사용자가 어떤 식으로 요구했고 어디까지 맡겼는지
- **결과가 어땠는가** — 한 번에 됐는지, 몇 번을 주고받았는지
- **막혔다가 푼 과정** — 가장 값어치 있는 부분이다. 증상, 원인, 해결을 적는다.
  기술 문서에서 설득력이 나오는 지점이므로 생략하지 않는다

## 분량

3~5줄이 기준이다. 막힌 과정이 있으면 더 써도 되지만, **한 세션에 한 항목**으로
묶는다. 커밋마다 남기면 정작 마감 때 신호가 묻힌다.

## 쓰지 않는 것

- 커밋 메시지에 이미 있는 내용의 반복
- 파일 목록이나 줄 수 같은 기계적 정보 (git 이력에 있다)
- 과장. 안 된 건 안 됐다고 쓴다
